# ที่มาของเสียงเดิม

คัดลอกแบบ byte-for-byte จาก `output/car-truth-v2/sfx/` ทั้ง 7 ไฟล์: amb, boing, brake, bump, pop, tread, whoosh (.mp3)

ไม่พบ README หรือ production ที่ระดับต้นทาง `output/car-truth-v2/` ซึ่งยืนยันผู้สร้าง/สัญญาอนุญาตของแต่ละไฟล์ จึงไม่อ้างว่าเป็น CC0 หรือมีสิทธิ์ใช้งานแล้ว ไฟล์เหล่านี้เป็นสำเนาสำหรับการทดสอบตาม brief เท่านั้น ไม่ได้อนุมัติการเผยแพร่หรือ commit เสียง มี sha256/ขนาด/ต้นทางรายไฟล์ใน `../kits/MANIFEST.json` ไม่มีการสร้างเสียงใหม่หรือเรียกบริการเสียง

## เสียงที่ Claude สังเคราะห์เอง (17 พ.ย. 2026) — ทำเอง ไม่มีลิขสิทธิ์ผู้อื่น ไม่ใช่ดนตรี
- `glide.mp3` เสียงหุ่นเคลื่อนที่แบบนุ่ม แทน `tread.mp3` (เจ้าของแจ้ง: ลูกสาวบอกว่าเสียงล้อเดิมดังและแสบหูมาก)
  สร้างด้วย ffmpeg: pink noise กรองช่วง 250–1100 Hz + sine 220 Hz เบามาก สั่นเบา 5 Hz · ไม่มีความถี่สูงเกิน 3 kHz (ต่ำกว่าเดิม ~37 dB) วนซ้ำได้ 3 วินาที
- `settle.mp3` เสียงหยุดนุ่ม แทน `brake.mp3` — sine 330 Hz สั้น + pink noise กรอง 200–900 Hz จางออก 0.3 วินาที
