# IMG-2 — ภาพเกาะทรงกว้างเตี้ยสำหรับเกมความจำบนมือถือ (ภาพก่อน โค้ดทีหลัง)
**model `gpt-6-astra` (medium) · timeout 5400 · ทำงานใน `D:/Littleummah/output/memory-mobile-island/` เท่านั้น (ห้ามแก้ไฟล์ในโปรเจกต์ ห้าม commit)**
ตอบภาษาไทย อ่าน `D:/Littleummah/AGENTS.md` ข้อ 1.5 และ **ข้อ 2 ส่วน "ข้อยกเว้น — การ์ดเกมความจำบนมือถือ"**

## ปัญหา
ภาพเกาะ `D:/Littleummah/public/games/memory/island.webp` มีผิวครีม (พื้นที่วางการ์ด) สูงเพียง ~34% ของความสูงภาพ
ตาราง 3 แถวของด่าน 2–3 จึงทำให้การ์ดบนมือถือแนวตั้ง (360–430px) เล็กแค่ราว 33–45px ซึ่งต่ำกว่า 64px
AGENTS บันทึกทางแก้ที่ถูกไว้แล้ว คือ **วาดภาพเกาะทรงกว้างเตี้ยสำหรับมือถือ ให้ผิวครีมสูง 55–60% ของภาพ**
ดูวิธีวาง `.isl-surface` ทับผิวเกาะได้ที่ `src/features/games/memory.css` (บรรทัด 30–60)

## งาน
1. สร้างภาพเกาะใหม่ 2–3 ตัวเลือก โดยใช้ `island.webp` เดิมเป็นภาพอ้างอิง ให้สไตล์ 3D พรีเมียม สี ฟ้า/เทอร์ควอยซ์/ขาว/ทอง และของประดับเข้าชุดกับเดิม
   - **ผิวครีมเรียบ** (ไม่มีลาย ไม่มีของวางทับ) กินพื้นที่ **55–60% ของความสูงภาพ** และกว้างเกือบเต็มภาพ
   - ของประดับอยู่แค่รอบขอบ ไม่บังผิวครีม
   - ไม่มีตัวหนังสือ ไม่มีคนหรือสัตว์ ไม่มีสัญลักษณ์ดนตรี
   - PNG พื้นโปร่งใส สัดส่วนเหมาะกับจอแนวตั้ง 360–430px
2. วัดกรอบผิวครีมด้วยสคริปต์ (หา bounding box ของผิวครีม เป็น % ของภาพ) ห้ามกะด้วยตา
   แล้วคำนวณว่าบนจอกว้าง 360, 390, 430px ตาราง 3×4 (และขนาดตารางของทุกด่าน ดูจากโค้ดเกม) จะได้การ์ดกว้างกี่ px
3. scan alpha: พื้นต้องโปร่งใสจริง และเกาะต้องทึบ
4. ทำแผ่นเทียบ `contact.png` วางภาพเดิมเทียบกับตัวเลือกใหม่ และวาดกรอบผิวครีมที่วัดได้ทับไว้
