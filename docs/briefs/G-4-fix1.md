1. **เกาะคนละแบบ** — ภาพหน้าเกม: เกาะกลมพื้นไม้ครีม ขอบทอง ฐานหินเทอร์ควอยซ์เหลี่ยม พุ่มไม้เขียวสองข้าง · ในเกม: เกาะสี่เหลี่ยมขอบน้ำเงิน → ใช้เกาะเดียวกับภาพหน้าเกม (แยกชิ้นหรือ gen ใหม่โดยใช้ภาพนั้นเป็น reference) มุมกล้องเดียวกัน
2. **บล็อกเป็นภาพแบนหน้าตรงลอยเหนือเกาะ** — ในภาพหน้าเกมบล็อกเป็นไม้ 3D มุมเฉียง ตั้งอยู่บนพื้นเกาะจริง มีเงา → บ้านที่สร้างต้องตั้งบนลานเกาะ ฐานบ้านแตะพื้น มีเงาตกพื้น บล็อกมุมกล้องเดียวกับเกาะ ลายไม้แบบในภาพ
3. **แบบบ้านเป็นกรอบเส้นประ** → เปลี่ยนเป็น "เงา/แบบจาง" ของบล็อกจริงบนลาน (บล็อกโปร่งแสงหรือรอยบนพื้น) ไม่ใช่กล่อง UI เส้นประ ช่องที่วางได้ตอนนี้ไฮไลต์นุ่มๆ
4. **ถาดบล็อกเป็นแผง UI ทางซ้าย** → ทำเป็นถาดไม้/ลังไม้ 3D (บนเกาะด้านหน้า หรือชิดใต้เกาะบนมือถือแนวตั้งแบบเกม sequence) ป้ายชื่อรูปทรงเล็กใต้บล็อกยังมีได้
5. บ้านที่สร้างเสร็จต้องดูเหมือนภาพหน้าเกม (ด่าน 1–2 อย่างน้อยหนึ่งแบบคือบ้านในภาพ: ฐานน้ำเงิน ประตูโค้งขาว คานเทอร์ควอยซ์ หลังคาเหลือง + ทรงกระบอกไม้สองข้าง)
