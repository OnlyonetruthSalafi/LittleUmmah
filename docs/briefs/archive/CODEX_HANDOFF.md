## 2. เกมนี้ทำงานยังไง

เส้นทาง `/games/shape-match` → `GamePlayer` → `GameShell` → **`ShapeBoard.tsx`**

- **เกาะ** `public/games/shape/island.webp` เป็นกระดาน ใช้ `IslandBoard` ตัวเดียวกับเกมความจำ
- **แผ่นฐานหยอดรูปทรง** เป็นภาพเดียวทั้งแผ่น วางบนผิวเกาะ หลุมวาดติดมากับภาพ
- **หลุมที่กดได้** เป็นปุ่มโปร่งใสวางทับตำแหน่งหลุมในภาพ ตำแหน่งอยู่ใน `HOLES` (`data/shapeArt.ts`)
  หาด้วยการสแกนหาคิ้วทองรอบหลุมในภาพจริง ไม่ได้กะเอา
- **บล็อกที่ลากได้** อยู่ใต้เกาะ ใช้ `DragItem` ตัวเดิม (แตะ→แตะ และลากได้ทั้งสองแบบ)
- **ตอนหยอดถูก** แผ่นทั้งแผ่นสลับไปเป็นภาพที่มีรูปทรง**ที่หยอดไปแล้วทั้งหมด**อยู่ในหลุม
  พร้อมประกายทองสามดวง แผ่นเรืองแสงวาบ และแผ่นเด้งรับ
- มี **ด่านเดียว** ใช้ครบห้ารูปทรงเสมอ (`levelCount: 1` ใน `presentation.ts`)
  ตัวเลือกด่าน ปุ่ม "ด่านต่อไป" และ "เลือกด่านใหม่" ซ่อนอัตโนมัติเมื่อ `levelCount === 1`

ตรรกะเกมใช้ของกลางเดิมหมด: `canPlace` / `shuffle` / `levelComplete` / `completionStars`
ความคืบหน้าและดาวเก็บผ่าน `gameProgress` (localStorage) เหมือนเกมอื่น ไม่ได้แก้อะไร

## 3. ภาพ 38 ไฟล์ และ pipeline

ต้นฉบับที่เจ้าของโปรเจกต์วาด อยู่ที่ `public/games/shape match/` (**gitignore แล้ว** รวม 57 MB)

```
object/     แผ่นฐานเปล่า 1 + เกาะ 1 + บล็อก 5
done/       หยอดแล้ว 1 ชิ้น (5 ใบ) + ครบห้า (1 ใบ)
done/2done  หยอดแล้ว 2 ชิ้น (10 ใบ)
done/3done  หยอดแล้ว 3 ชิ้น (10 ใบ)
done/4done  หยอดแล้ว 4 ชิ้น (5 ใบ)
```

รวม 32 ใบ = **ทุกชุดย่อยของห้ารูปทรงพอดี** เกมจึงแสดงผลสะสมได้จริง

แปลงด้วย `node scripts/prepare-shape-art.mjs` ออกไปที่ `public/games/shape/` (3.6 MB, commit ตัวนี้)
ชื่อไฟล์เป็นบิตมาสก์เรียงตาม `shapeOrder` = circle, square, triangle, rectangle, star
เช่น `plate-10101.webp` = หยอดวงกลม สามเหลี่ยม ดาว แล้ว

สคริปต์ **อ่านเองว่าภาพใบไหนคือสถานะอะไร** โดยเทียบสีตรงตำแหน่งหลุมกับภาพอ้างอิง
แล้วใช้จำนวนชิ้นจากชื่อโฟลเดอร์เป็นหลักยึด และมีตัวตรวจว่าต้องได้ครบ 32 มาสก์ ไม่ซ้ำไม่ขาด
**ถ้าเพิ่มหรือเปลี่ยนภาพแล้วสคริปต์ throw แปลว่ามันจับคู่ผิด อย่าปิดตัวตรวจ ให้แก้ที่การอ่านภาพ**

sha256 ของต้นฉบับทุกไฟล์บันทึกไว้ใน `scripts/source-images.json` แล้ว

มี `node scripts/measure-island.mjs <ไฟล์>` ไว้วัดผิวครีมของภาพเกาะ
คืนค่า `--surface-l/r/t/b` ที่เอาไปใส่ CSS ได้เลย ใช้ตอนเปลี่ยนภาพเกาะ

## 5. กับดักที่เจอมาแล้ว — อย่าเดินซ้ำ

1. **`next/image` ทำ alpha ของแผ่นฐานหาย กลายเป็นกล่องดำ**
   แก้ด้วย `unoptimized` ที่ `<Image>` ของแผ่นฐานและบล็อก
   ไฟล์เป็น WebP 900px ราว 100KB ที่ย่อมาพอดีแล้ว ไม่ได้อะไรเพิ่มจากการ optimize ซ้ำ
   ถ้าเอา `unoptimized` ออก กล่องดำจะกลับมา

2. **ภาพชุด 2done / 3done / 4done เป็น PNG พื้นหลังดำทึบ ไม่มี alpha** (ชุดแรกมี)
   `cutBlackBackground()` ในสคริปต์ไล่ลบเฉพาะสีดำที่ต่อเนื่องกับขอบภาพ ไม่แตะเงาเข้มกลางแผ่น
   แล้ว**ละเลงสีขอบแผ่นออกไปในพื้นที่โปร่งใส 10 รอบ** ด้วย
   ถ้าลบแค่ alpha แล้วปล่อยค่า RGB เป็นดำ พอย่อภาพ สีดำจะถูกเฉลี่ยกลับเข้ามาเป็นขอบดำ
   (วัดจริง: ภาพ 900px สะอาด แต่ตัวที่ย่อเหลือ 267px มีพิกเซลดำทึบ 18,223 จุด)

3. **แคชภาพของ dev server ค้าง** หลังแปลงภาพใหม่ ต้อง `rm -rf .next/cache/images`
   แล้ว**รีสตาร์ท dev server** ล้างโฟลเดอร์เฉยๆ ไม่พอ

4. **สกรีนช็อตติดภาพก่อนวาดเสร็จ** เกาะหรือแผ่นจะหายไปทั้งใบ ยิงซ้ำอีกครั้งจะเห็น อย่าไปไล่แก้โค้ด

5. **ภาพแต่ละใบเรนเดอร์แยกกัน วางทับกันไม่ตรงเป๊ะ** เจ้าของโปรเจกต์บอกว่าไม่ต้องซีเรียสเรื่ององศา
   สคริปต์ trim แล้ววางกึ่งกลางผืนผ้าใบเดียวกัน (900 x 860) ซึ่งลดการกระตุกได้พอแล้ว

6. **`prefers-reduced-motion` ในโปรเจกต์นี้ตัดแค่ระยะเวลา ไม่ตัดค่า transform**
   สัญญาณที่ต้องเห็นเสมอจึงต้องใช้ `box-shadow` หรือ `filter` ไม่ใช่ transform

## 6. ข้อแลกเปลี่ยนที่เจ้าของโปรเจกต์รับทราบแล้ว

- **บนมือถือ หลุมสูงราว 49–54px และบล็อกราว 50–57px ต่ำกว่ามาตรฐาน 64px**
  จะให้ครบ 64px ต้องขยายแผ่นฐานจนกว้างราว 87% ของกระดาน ซึ่งจะบังเกาะจนไม่เหลือ
  หรือไม่ก็ต้องเลื่อนจอ ซึ่งขัดคำสั่ง "ให้เกาะ ถาด และวัตถุอยู่ในหน้าจอเดียวกัน"
  บันทึกเหตุผลไว้ใน `AGENTS.md` ข้อ 2 ต่อจากข้อยกเว้นของเกมความจำแล้ว
  ปรับได้ที่ `--surface-l/r` ใน `shape.css` กับค่า `w` และ `h` ใน `HOLES`
  บนแท็บเล็ตและเดสก์ท็อปเกิน 64px สบาย

- **ทั้งหน้าถูกบีบให้พอดีหนึ่งหน้าจอ** (วัดได้ 786 จาก 786 บนจอสูง 786px)
  ชื่อเกมถูกดึงกลับมาอยู่แถวเดียวกับปุ่ม ปุ่มคำใบ้ลอยทับมุมบนขวาไม่กินแถว
  `--shp-chrome` ใน `shape.css` คือความสูงรวมของแถบอื่นๆ ใช้จำกัดขนาดเกาะด้วย `100dvh`
  **ถ้าเพิ่มแถบอะไรเข้ามาอีก ต้องปรับ `--shp-chrome` ตาม ไม่งั้นหน้าจะเลื่อน**

- ป้ายชื่อใต้บล็อกทั้งห้าถูกเอาออกเพราะเบียดกันจนอ่านไม่ออก เหลือป้ายเดียวที่ขึ้นตอนเลือกชิ้น
  ชื่อไทยและอังกฤษครบยังอยู่ใน `aria-label` ของทุกชิ้นสำหรับ screen reader
