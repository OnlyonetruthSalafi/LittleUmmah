# C-6 — เกมจับคู่อักษรอาหรับให้ครบ 28 ตัว

## บริบท
เกมจับคู่อักษร (`src/features/games/data/content.ts`, `games/games/MatchingBoard.tsx`, `data/presentation.ts`) ใช้เพียง 7 ตัวแรก ห้องเรียนอาหรับ (`src/features/arabic/data/classroom.ts`) มีครบ 28 ตัวแล้ว
หมายเหตุ: งานอื่นที่กำลังแก้ `MatchingBoard.tsx` และ `games.css` (เกมแนวนอน, ฟอนต์อาหรับ) จะรวมทีหลัง — แก้สองไฟล์นี้ให้น้อยและแยกเป็นก้อนชัด

## งาน
- ให้ทั้ง 28 ตัวเข้าถึงได้ในเกม: แบ่งเป็นชุด (เช่น 7 ชุดตามลำดับห้องเรียน หรือชุดละ 4 ตัวตรงกับชุดในห้องเรียน — เลือกที่ทำให้เด็กเรียนต่อเนื่องจากห้องเรียน แล้วอธิบายเหตุผล)
- เพิ่มทางเลือกชุดภายในกระดานเดิม (ปุ่มเด็ก ≥64px, ไทยนำ) หรือหมุนชุดตามด่าน/รอบ — ห้ามเพิ่มด่านที่ 4 (โครง `levels` เป็น tuple 3)
- ตัวอักษรเป็นข้อความจริง ใช้ฟอนต์ตามระบบเดิม (ไม่ต้องรอฟอนต์อาหรับใหม่) ตรวจว่าจุดและรูปอักษรไม่ถูกตัดบนมือถือ
- ใช้คำสั่ง/เสียงพากย์เดิม ไม่ต้องอัดเสียงชื่ออักษรรายตัว (การออกเสียงอาหรับสังเคราะห์ยังไม่อนุญาต ตามแผน P5-3)
- ห้ามทำลายเกมจับคู่สี/แยกหมวด และความก้าวหน้า/ดาว Learning Stars เดิม

## เกณฑ์ผ่าน
- test ใน `tests/game-center.test.mjs` (หรือไฟล์ใหม่) ยืนยันว่าทั้ง 28 ตัวอยู่ในชุดใดชุดหนึ่ง ไม่ซ้ำ ไม่ขาด และรูปอักษรตรงกับ `classroom.ts`
- `check-game-routes.mjs` และชุดตรวจเบราว์เซอร์เกมผ่าน พร้อมกรณีชุดใหม่ ภาพหน้าจอทุกชุดที่ 360×780 และ 844×390
