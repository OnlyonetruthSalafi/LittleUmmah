> "ทำระบบดาวเรียนรู้ พร้อมกับระบบออปชั่นในเมนูผู้ปกครอง เพื่อจำกัดเวลาเล่นหน้าจอของลูก โดยมีครูนูรีเตือนเมื่อครบเวลา
> มีเสียงให้เด็กไปบอกผู้ปกครองให้ช่วยปลดล็อกให้ หรือไปเกาะเรียนรู้ จุดประสงค์เพื่อให้ผู้ปกครองสอนเด็กให้เรียนก่อนเล่นได้ด้วย

> และจัดทำ setting ใส่ไว้ในเมนูผู้ปกครอง"

ตอนนี้ระบบดาวเรียนรู้**ยังไม่มีในโค้ดเลย** เกมทุกเกมเล่นได้ไม่จำกัด ดาวรางวัลเดิมถูกซ่อน (`SHOW_REWARD_STARS = false` ใน `src/lib/rewardStars.ts`) ห้ามเปิดดาวเดิมกลับมา และห้ามเอาดาวเดิมมาปนกับดาวเรียนรู้

## A. ดาวเรียนรู้ (Learning Stars) — กติกาที่ตัดสินแล้ว ห้ามเปลี่ยน
1. ชื่อ **ดาวเรียนรู้ / Learning Stars** ใช้ไอคอน SVG ใหม่ `src/components/icons/LearningStarIcon.tsx` (ดาวทองมีหนังสือเปิดเล็กๆ ตรงกลาง) ต้องดูต่างจาก `StarIcon` เดิมชัดเจน
2. **ได้ดาว:** ทำบทเรียนจบ 1 บท = 1 ดาว **บทเดียวกันให้ได้วันละครั้ง** (นับตามวันที่ในเครื่อง) ห้ามให้ดาวจากการเล่นเกม
   - เกาะมารยาท + เกาะสำรวจโลก: จุดเดียวกับที่เรียก `markPractised` (ดูการ์ตูนจนจบ / ฟังบทจนจบ) key `moral:<id>`, `explore:<id>`
   - เรื่องเล่า (ตู้อัลกุรอาน + ตู้หะดีษทุกตู้): อ่านถึงหน้าสุดท้ายของเล่ม (`StoryBook`) key `story:<slug>` — ตอนนี้ยังไม่มี hook ต้องเพิ่ม
   - ห้องเรียนอาหรับ (`Classroom.tsx`): เรียนอักษรจบหนึ่งตัวตามที่ห้องเรียนนับว่า "เรียนแล้ว" key `arabic:<letter>`
   - ห้องภาษาอังกฤษ/ไทย (`src/features/languages/`): ถ้ามีจุดที่นับว่าจบบท ให้ใช้ key `lang:<course>:<id>` ถ้าไม่มีจุดจบที่ชัดเจน อย่าประดิษฐ์ ให้รายงาน
   - ได้ดาวแล้วแสดงป้ายเล็ก "ได้ดาวเรียนรู้ +1" มีไอคอน + เสียงครู `ls-earned` (ไม่กระพริบ ไม่เด้งวน ข้อ 2.1) ไม่ขัดการ์ตูน/หน้าหนังสือที่กำลังเล่น
3. **ใช้ดาว:** 1 ดาว = 1 "รอบเล่น" ที่อยู่**จนกว่าจะผ่านหนึ่งด่าน** — เก็บเป็นเครดิต `activeRound` ข้ามการออกแล้วกลับเข้ามา
   - เริ่มด่านขณะมีเครดิต = ไม่หักเพิ่ม (เริ่มใหม่ ออกกลางด่าน เปลี่ยนด่าน เปลี่ยนเกม) **ผ่านด่าน = เครดิตหมด** ด่านต่อไปต้องใช้ดาวใหม่
   - **ไม่นับเวลาในกติกาดาว** (เวลาเป็นอีกระบบในข้อ B)
   - บังคับที่จุดเดียว `GameShell.start()` (และเกมใดที่ไม่ผ่าน GameShell ให้หาแล้วครอบให้ครบ รายงานรายชื่อ) ต้องครอบทุกทาง:
     GameIntro, VoiceIntro, GameTutorial `onDone`, ปุ่มเริ่มใหม่/ด่านต่อไป/เล่นอีกครั้ง, journey ที่เริ่มด่านถัดไปอัตโนมัติ,
     ลิงก์จากหน้าแรกเข้าเกมตรง, ทั้ง route `/games/*` และ `/learn/games`, puzzle ที่ใช้ progress id ต่อภาพ
   - **ตรวจดาวก่อน `enterGameFullscreen()`** ถ้าไม่มีดาว ไม่เข้าเต็มจอ ไม่เริ่มนับถอยหลัง
4. **ดาวตั้งต้น 3 ดวง ให้ครั้งเดียวต่อเครื่อง** + **เล่นฟรีวันละ 1 รอบ** (รอบแรกของวันได้เครดิตโดยไม่หักดาว)
5. **เก็บดาวได้สูงสุด 20 ดวง** ครบแล้วไม่เพิ่ม (ป้ายบอก "ดาวเต็มแล้ว")
6. **ดาวหมด:** ไม่เริ่มด่าน แสดงหน้าครูนูรี (ภาพหุ่นเดิมใน `public/Character/`) + เสียง `ls-empty` และปุ่ม ≥64px:
   "ไปเกาะเรียนรู้" (ไปหน้าแรกที่โซนเรียน หรือ `/learn/moral` — เลือกแล้วรายงาน) และ "สำหรับผู้ปกครอง" (เปิด ParentGate → ให้ดาว +1/+3 หรือไปหน้าตั้งค่า)
7. แสดงยอดดาวเรียนรู้ที่หัวเกาะเกม (แทน `HubProgress` ที่ซ่อนอยู่ ไม่ต้องลบดาวเดิม) และบนหน้าเริ่มเกม: บอกว่ารอบนี้ฟรีวันนี้ / ใช้ 1 ดาว / มีเครดิตอยู่แล้ว ข้อความไทยนำ + ไอคอน ห้ามสื่อด้วยสีอย่างเดียว
8. ผู้ปกครอง**ปิดระบบดาวได้**ในหน้าตั้งค่า (ค่าเริ่มต้น = เปิด) ปิดแล้วเกมเล่นได้ไม่จำกัดเหมือนตอนนี้ ยอดดาวยังเก็บไว้
9. ห้าม: ดาวลดเพราะเล่นแพ้, รางวัลสุ่ม, leaderboard, streak ที่ขาดแล้วเสียของ, ล็อกกลางบทเรียน

## B. จำกัดเวลาเล่น (ตัวเลือกผู้ปกครอง)
1. **ค่าเริ่มต้น = ปิด** เปิดในหน้าตั้งค่าแล้วเลือกนาทีต่อวัน: 15 / 20 / 30 / 45 / 60 / 90 (ค่าที่เลือกไว้ตอนเปิดครั้งแรก = 30)
2. **นับเฉพาะเกาะเล่น = เกาะเกม (ทุกเกม รวมหน้าเกาะเกม) + เกาะศิลปะ** — ห้ามใช้ `HOME_ISLANDS.play` เป็นตัวกำหนด เพราะมีเรื่องเล่า/สำรวจโลกอยู่ด้วย
   เกาะเรียนรู้ทั้งหมด (อาหรับ/ภาษา มารยาท เรื่องเล่า สำรวจโลก) **ไม่นับเวลาและไม่ถูกล็อก** เพราะครูส่งเด็กไปที่นั่น
   ศิลปะ: นับเวลา แต่ไม่ใช้ดาว
3. นับเฉพาะตอนหน้าจอแสดงอยู่ (`visibilityState === 'visible'`) รวมต่อวันตามวันในเครื่อง ใช้ร่วมกันหลายแท็บ (event `storage`) ไม่นับซ้ำเมื่อเปิดสองแท็บ
4. **เหลือ 2 นาที:** ครูเตือน `time-warn` + ป้ายเล็ก (ไม่ขัดการเล่น)
5. **ครบเวลา:** ห้ามตัดกลางด่าน — ให้เล่นด่านที่กำลังเล่นจนผ่าน (หรือเกินได้สูงสุด 5 นาที) แล้วจึงล็อก ศิลปะล็อกทันทีที่ครบ (ภาพที่ระบายไว้ต้องไม่หายถ้าเดิมมีการเก็บ)
   หน้าล็อก: ครูนูรี + เสียง `time-up` + ปุ่ม "ไปเกาะเรียนรู้" และ "สำหรับผู้ปกครอง"
   ParentGate → "เพิ่ม 15 นาที" / "เพิ่ม 30 นาที" / "ไม่จำกัดถึงพรุ่งนี้" / "ไปหน้าตั้งค่า" — ปลดแล้วเล่นเสียง `unlocked`
6. **overlay ต้อง render อยู่ใน fullscreen element ของเกม** (portal ไป `body` จะไม่เห็นตอนเต็มจอ) และอยู่ใน RotateGate/แนวนอนได้
7. เมื่อทั้ง A และ B เปิด: ล็อกเวลามาก่อน (ครบเวลาแล้วมีดาวก็เล่นไม่ได้)

## C. ParentGate (ตัวเดียว ใช้ทุกที่)
`src/components/parents/ParentGate.tsx` — คำถามสำหรับผู้ใหญ่: คูณเลขสองตัว 6–9 เขียนเป็นคำ (ไทย "เจ็ด คูณ แปด" / en "seven times eight") พิมพ์คำตอบเป็นตัวเลข
ตอบผิดเปลี่ยนคำถาม ไม่มีนับถอยหลังลงโทษ ปุ่ม/ช่อง ≥48px focus ชัด อ่านด้วย screen reader ได้ ห้ามใช้ `window.confirm/prompt`
ผ่านแล้วจำไว้ในหน่วยความจำ 10 นาที (ไม่เก็บลง storage)
**ใช้กับ:** ปิด/เปิดระบบดาว, ตั้งค่าเวลา, หน้าล็อกเวลา, หน้าดาวหมด, **และปุ่มล้างความคืบหน้า** (ตอนนี้ไม่มี gate — ถ้าไม่กั้น เด็กล้างแล้วได้ดาวตั้งต้นใหม่และเวลาวันนี้กลับเป็นศูนย์)

## D. การเก็บข้อมูล
- localStorage key ใหม่ขึ้นต้น `lu-ls-` (ยอดดาว, รายการที่ได้ดาววันนี้, activeRound, วันฟรี, นาทีที่ใช้วันนี้, ปลดล็อกวันนี้) และ `lu-settings` (ดาวเปิด/ปิด, เวลาเปิด/ปิด + นาที, flag "ให้ดาวตั้งต้นแล้ว")
- **ล้างความคืบหน้า:** ล้างยอดดาว/รายการวันนี้/activeRound — **ไม่ล้าง** `lu-settings` (รวม flag ดาวตั้งต้น) และไม่ล้างนาทีที่ใช้วันนี้ เหมือนที่ไม่ล้างการตั้งค่าเสียง
- อ่าน/เขียนพังไม่ได้ (โหมดส่วนตัว) → เกมเล่นได้ปกติแบบไม่จำกัด ห้ามล็อกเด็กเพราะ storage เสีย
- ใส่ key ทั้งหมดใน `ClearProgress.tsx` และข้อความ "ข้อมูลส่วนตัว" ใน `parents/content.ts`
- เขียนตรรกะเป็น module บริสุทธิ์ทดสอบได้ (`src/features/learning-stars/` หรือที่เหมาะ) + unit test: ได้ดาววันละครั้งต่อบท, เพดาน 20, ตั้งต้นครั้งเดียว, ฟรีวันละรอบ, เครดิตอยู่จนผ่านด่าน, ข้ามวัน, storage พัง, นับเวลาเฉพาะ visible, เตือน 2 นาที, ผ่อนจนจบด่าน/สูงสุด 5 นาที, ปลดล็อก +15/+30/ทั้งวัน

## E. หน้าผู้ปกครองใหม่
1. `/parents` เป็นหน้าเมนู: หัวเรื่อง + **เมนูการ์ด/ปุ่ม** ไป
   - **ตั้งค่า** → หน้าใหม่ `/parents/settings`
   - **แนวทางเนื้อหาและหลักฐาน** → หน้าใหม่ `/parents/evidence`
   - และหัวข้อสั้นในหน้าเดิม: Little Ummah คืออะไร, แนวทางเนื้อหา (ย่อ), เสียงอ่าน, ข้อมูลส่วนตัว, คำแนะนำ, ไปยังช่วงวัย
2. **ย่อหลักฐานศาสนาเป็นลิงก์:** ในหน้า `/parents` เหลือเพียงสรุปหนึ่งย่อหน้าต่อเรื่อง (ภาพใบหน้าว่าง / ภาพถ่ายสัตว์) + ลิงก์ "ดูหลักฐานทั้งหมด" ไป `/parents/evidence`
   **หน้า evidence ต้องแสดงตัวบทเดิมครบทุกข้อ** (อาหรับ คำแปล ที่มา ลิงก์ Shamela หมายเหตุอัลบานีย์และอัลเลาะญ์นะฮ์) จาก `content.ts` เดิม — **ห้ามแก้ ห้ามตัด ห้ามแปลใหม่** แค่ย้ายที่แสดง
   เพิ่ม unit test ว่าตัวบท `SAHABA` `ULAMA` `PHOTO` (arabic, tr, source, href) ไม่เปลี่ยนจากเดิม (snapshot ค่าปัจจุบัน)
   ข้อความสรุปที่เขียนใหม่ให้ใส่ `REVIEW-RELIGIOUS` ในรายงาน Claude ตรวจเอง
3. `/parents/settings` (ผู้อ่านผู้ใหญ่ ปุ่ม ≥48px):
   - **ดาวเรียนรู้:** เปิด/ปิด, ยอดตอนนี้, ให้ดาว +1/+3 (ไม่เกินเพดาน), คำอธิบายกติกาสั้นๆ
   - **จำกัดเวลาเล่น:** เปิด/ปิด, เลือกนาที, ใช้ไปวันนี้กี่นาที, ปุ่มรีเซ็ตเวลาวันนี้, บอกตรงๆ ว่าใช้ได้เฉพาะเบราว์เซอร์นี้ในเครื่องนี้ และเด็กโตอาจเลี่ยงได้ด้วยการล้างข้อมูลเบราว์เซอร์
   - **เสียง:** สวิตช์เปิด/ปิดเสียงเดิม (`soundStore`) — ใช้ตัวเดิม ห้ามสร้างคู่ขนาน
   - **ล้างความคืบหน้า** (ย้ายมาจากหน้าหลัก ผ่าน ParentGate)
   - การเปลี่ยนค่าทุกอย่างต้องผ่าน ParentGate ก่อน (ดูได้โดยไม่ต้องผ่าน)
   - สวิตช์ใช้ `role="switch"` + `aria-checked` + ข้อความเปิด/ปิด
4. แก้ข้อความที่ตอนนี้ไม่ตรงความจริง (เขียนเฉพาะสิ่งที่เว็บทำจริง):
   - "แบ่งเป็นหกเกาะ" → ให้ตรงกับเกาะที่มีจริงตอนนี้ (ดู `src/lib/categories.ts`)
   - "เรื่องเล่าใช้เนื้อหาจากอัลกุรอาน" → อัลกุรอานและหะดีษเศาะฮีห์ (มีตู้หะดีษแล้ว) — `REVIEW-RELIGIOUS`
   - "ดูหลักฐานในหัวข้อถัดไป" → ชี้ไปลิงก์หน้าหลักฐาน
   - ข้อมูลส่วนตัว: เพิ่มดาวเรียนรู้ เวลาเล่น การตั้งค่าใหม่
   - เพิ่มย่อหน้าอธิบายดาวเรียนรู้และการจำกัดเวลาในหัวข้อ "คำแนะนำ" เช่น ชวนลูกเรียนก่อนเล่น
5. ทุกข้อความเป็น `Text {th, en}` ใน `content.ts` หรือ dict ลิงก์ใช้ `LocaleLink` เพิ่ม metadata ของสองหน้าใหม่ (noindex ไม่จำเป็น ใช้ `pageMetadata` แบบหน้าเดิม)
6. ลิงก์ "สำหรับผู้ปกครอง" ใน SiteHeader คงไว้ ชี้ `/parents`
