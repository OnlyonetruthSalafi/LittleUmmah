## ปัญหา (เจ้าของโปรเจกต์สั่ง 8 พ.ย. 2026: "เกมต้องอลังการใกล้เคียงกับเกาะด้านหน้ามากที่สุด")
ภาพเป้าหมาย: `public/games/hub/balance-scale.webp` — เกาะทรายครีมขอบทองหยัก ฐานหินเทอร์ควอยซ์เหลี่ยม ต้นไม้เขียวสองข้าง,
ตาชั่งเสาเทอร์ควอยซ์ ฐานกลมน้ำเงินขอบทอง คานทองมีลูกกลมปลาย ยอดเสามีลูกทอง, **จานทองแขวนด้วยโซ่/ก้านทองสามเส้น** ลอยเหนือเกาะ
ฉากตอนนี้: เกาะคนละแบบ (ลานสี่เหลี่ยมมีแผงน้ำเงิน) จานวางเกือบติดพื้น เชือกเส้นบาง → ทำใหม่ให้เป็นเกาะ/ตาชั่งชุดเดียวกับภาพหน้าเกม

## งาน
- เกาะและตาชั่งแยกชิ้นจากภาพหน้าเกม หรือ gen ใหม่โดยใช้ภาพนั้นเป็น reference (ฐาน+เสา, คาน, จานพร้อมก้านแขวน แยกชิ้นโปร่งใส) ให้คานเอียงและจานขึ้นลงตามน้ำหนักแบบที่ทำใน fix1 ต่อไป
- จานแขวนสูงเหนือเกาะแบบในภาพ ของบนจานตั้งอยู่ในจานจริง (เงาตกในจาน) ไม่ใช่ลอยทับ
- ถาดบล็อกที่เด็กหยิบ: วางบนเกาะ (ลานทรายด้านหน้า) หรือถาดไม้/ทองใต้เกาะที่กลมกลืน ไม่ใช่แผง UI แยก
- ป้ายข้อความ (ชื่อของ หน่วย) คงพื้นทึบอ่านง่ายตาม fix1 แต่ต้องไม่บังตัวตาชั่ง
- ตรรกะ เสียง ด่าน คีย์บอร์ด คงเดิม (unit test เดิมผ่าน)
