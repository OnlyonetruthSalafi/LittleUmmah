# VIP-4 — เส้นทางต่อจากร้านน้ำปั่น + เกมที่ 2 "สวนผัก" (แผนงาน Claude)

เจ้าของโปรเจกต์สั่ง 23 พ.ย. 2026 (ไปนอน 5 ชม. ให้ Claude ตัดสินใจและสั่งงานแทนได้ ใช้ Codex ทำภาพ):
"ทำเส้นทางไปเกมอื่นๆ ต่อจากร้านน้ำผลไม้ปั่น เช่น สั่งอาหาร เกมปลูกผัก เกมแข่งรถ … ห้ามเป็นเกมแบนๆ ต้องมีกลไกโต้ตอบที่น่าสนใจของตัวละคร ทำให้เสร็จทีละเกม"

## กฎคุณภาพของทุกเกมใหม่ในโซน VIP (Claude ตั้ง)
1. มี **ลูป 3 ชั้น**: การกระทำวินาทีต่อวินาที (ลาก เท ดึง) → เป้าหมายรอบ (คำขอของตัวละคร) → ความคืบหน้ายาว (ปลดของ/สูตร/พื้นที่ด้วยเหรียญร้านเดิม)
2. **ตัวละครโต้ตอบจริง**: เพื่อนหุ่นยนต์มีคำขอเป็นเสียงพากย์ เปลี่ยนท่า (think/point/cheer) ตามสถานการณ์ และตอบสนองต่อสิ่งที่เด็กทำ ไม่ใช่ป้ายนิ่ง
3. **มีสถานะที่เปลี่ยนตามเวลา/การดูแล** ไม่ใช่กดถูกแล้วจบ (เช่น ต้นไม้ขาดน้ำแล้วเหี่ยว)
4. **ความยากไล่ระดับ**: คำขอเริ่ม 1 ชนิด → หลายชนิด → ต้องวางแผนลำดับ
5. ทำงานบนมือถือแนวตั้ง 360px, ปุ่ม/ของที่เด็กกด ≥ 64px, ทุกการลากมีทางกดคีย์บอร์ดแทน, ไม่มีกระพริบ/ลอยวนตลอด
6. ข้อ 1 ของ AGENTS: ภาพไม่มีใบหน้า (ยกเว้นหุ่นยนต์) ไม่มีตัวหนังสือ ไม่มีสัตว์/แมลง ไม่มีดนตรี

## เส้นทางบนแผนที่โลก
- ต่อทางเดินจากร้านน้ำปั่น (630,230) ข้ามสะพานไปทางตะวันออกสู่ "สวนผัก"
- ปลดเมื่อขายน้ำปั่นครบ 3 แก้ว (ก่อนหน้านั้นสะพานยังอยู่ในหมอก แตะแล้วบอกเงื่อนไข)
- จุดถัดไปที่ยังอยู่ในหมอก (แสดงหมุดล็อก): "ร้านอาหาร" (สั่งอาหาร ใช้ผักจากสวน) และ "สนามแข่งรถ"

## เกมที่ 2: สวนผักของเพื่อน (`/games/vip/garden`)
- แปลงดิน 4 แปลง (ซื้อเพิ่มเป็น 6) วางแบบ 2.5D
- ลำดับต่อแปลง: ดินแข็ง/วัชพืช → ลากจอบพรวน → เลือกเมล็ด → ลากบัวรดน้ำ → โต 3 ขั้น (ต้นอ่อน → ต้นกลาง → พร้อมเก็บ) ต้องมีน้ำจึงโต น้ำหมดแล้วเหี่ยวและหยุดโต
- วัชพืชงอกแทรกระหว่างโต ต้องดึงออก (ลากขึ้น) ไม่งั้นโตช้า
- เก็บเกี่ยวโดยดึงขึ้น ผักลงตะกร้า แล้วลากตะกร้าไปให้เพื่อนที่รั้ว
- เพื่อนมาที่ประตูรั้ว ให้สลาม ขอผัก (เสียงพากย์) ระหว่างรอทำท่าคิด พอได้ครบแสดงท่าดีใจ จ่ายเหรียญร้าน
- เมล็ดเริ่มต้น: แครอท ผักกาด · ซื้อเพิ่ม: มะเขือเทศ ข้าวโพด ฟักทอง · อัปเกรด: แปลงเพิ่ม, สปริงเกอร์ (รดน้ำทุกแปลง)
- เซฟแยก `little-ummah:games:garden:v1` ใช้เหรียญร่วมกับร้านน้ำปั่น (updateShop)
