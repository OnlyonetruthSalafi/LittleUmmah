# C-4 — เกมความจำ: คลังภาพสิ่งของใหม่ 8 ภาพ
**model `gpt-6-astra` (medium) · timeout 9000 · worktree `D:/Littleummah-c4` · พอร์ต 3114**
อ่าน `D:/Littleummah/docs/briefs/_content-common.md` ก่อน

## บริบท
เกมความจำ (`src/features/games/data/memoryArt.ts`, `games/games/MemoryBoard.tsx` หรือไฟล์บอร์ดความจำที่ใช้จริง, `scripts/prepare-memory-art.mjs`) เลือกภาพด้วย `slice(0, count)` — ภาพท้าย array จึงไม่เคยถูกเล่น
ข้อยกเว้นขนาดการ์ดบนมือถือ (AGENTS ข้อ 2) ใช้อยู่ ห้ามขยาย `.isl-surface`

## งาน
- สร้างภาพการ์ดใหม่ 8 ภาพตามสไตล์/ขนาด/พื้นหลังโปร่งใสของภาพเดิม: เช่น รถของเล่น ลูกบอล ร่ม บัวรดน้ำ ถ้วย ตะกร้า กระถางต้นไม้ บล็อกไม้ — **สิ่งของเท่านั้น** ไม่มีใบหน้าบนวัตถุ ไม่มีตัวหนังสือ
- เปลี่ยนการเลือกภาพเป็นสุ่มจากคลังทั้งหมดต่อรอบ (ใช้ seed/สุ่มแบบที่ไม่ทำให้ hydration mismatch — สุ่มฝั่ง client หลัง mount หรือแบบเดิมของโปรเจกต์) ให้ภาพเดิมและใหม่ถูกเล่นได้ทั้งหมด ทุกค่ามีคู่ครบ จำนวนการ์ดต่อด่านเท่าเดิม
- ภาพแยกต้องแยกกันชัดเมื่อเป็นการ์ดเล็กบนมือถือ (สีและรูปทรงต่างกัน)

## เกณฑ์ผ่าน
- `tests/memory-game.test.mjs` (หรือใหม่): คลังมีภาพครบ, การสุ่มให้คู่ครบ ไม่ซ้ำเกินคู่, ทุกภาพมีโอกาสถูกเลือก
- ชุดตรวจเบราว์เซอร์ของเกมความจำผ่าน + ภาพหน้าจอ 3 ด่านที่ 360×780 และ 1280×720 · scan alpha ภาพใหม่
