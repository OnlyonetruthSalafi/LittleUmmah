## กฎบังคับ
- หุ่นยนต์เท่านั้น ไม่มีคน สัตว์ แมลง ตัวหนังสือ ตัวเลข โลโก้ สัญลักษณ์ดนตรี
- PNG โปร่งใสจริง มุมภาพ alpha 0 เนื้อหุ่น alpha 255 ไม่มีพื้นหรือเงาพื้นสีเทา — ตรวจด้วยสคริปต์ก่อนส่ง
- ทำภาพเทียบ `compare.png` (ต้นแบบซ้าย ท่าใหม่ขวา ทั้งสามตัว) ตรวจด้วยสายตาว่าดีไซน์ตรงต้นแบบ ถ้าเพี้ยนให้ทำใหม่ภายในงบ
