# ART-FIX-1 — เกาะศิลปะบนมือถือ: ลากพู่กันจากถาดด้วยนิ้ว + ภาพตัวอย่างแนวนอนใหญ่ขึ้น
**model `gpt-6-astra` (medium) · timeout 7200 · worktree `D:/Littleummah-c13` (มีงาน C-1 + C-13 staged อยู่แล้ว ต่อยอดได้ ห้าม commit/push/reset) · พอร์ต 3123**
อ่าน `AGENTS.md` ข้อ 2, 2.1 และอ่านโค้ด `src/features/art/` (`ArtStudio.tsx`, `PaintSurface.tsx`, `paint.ts`, `art.css`) ก่อน

## ปัญหาที่เจ้าของโปรเจกต์เจอบนมือถือจริง (8 พ.ย. 2026)
1. **ใช้เมาส์:** เลือกสีที่ถาด แล้วพู่กันตามเคอร์เซอร์ไปที่ภาพได้ลื่นๆ
   **ใช้นิ้ว:** ลากพู่กันจากถาดมาที่ภาพ **ไม่ได้** — แตะที่ภาพแล้วพู่กันกระโดดไปตรงนั้นเลย ไม่เหมือนตอนใช้เมาส์
2. **ภาพตัวอย่าง (`.art-example`) เล็กเกินไปเมื่อจอแนวนอน** บนมือถือ

## ต้องการ
1. **ลากพู่กันด้วยนิ้ว:** กดนิ้วที่หลุมสีในถาด แล้วลากนิ้วออกมา — พู่กันต้องตามนิ้วไปตลอดทาง (เหมือนถือพู่กันจุ่มสีแล้วยกไปที่ภาพ)
   เมื่อนิ้วลากเข้าไปในภาพ ให้เริ่มระบายต่อในลากเดียวกันได้เลย (ชิ้นที่ระบายคือชิ้นที่นิ้วเข้าไปถึงก่อน สีไม่ล้นชิ้นตามกฎเดิม) ปล่อยนิ้ว = จบลาก
   การแตะหลุมสีเฉยๆ ยังเลือกสีได้เหมือนเดิม และแตะ/ลากในภาพโดยตรงยังระบายได้เหมือนเดิม (พู่กันโผล่ที่นิ้วได้ ไม่ใช่ปัญหา ถ้าเริ่มจากภาพเอง)
   ใช้ Pointer Events + `setPointerCapture` / `touch-action: none` เฉพาะจุดที่ต้องการ ห้ามทำให้ทั้งหน้าเลื่อนไม่ได้โดยไม่จำเป็น ห้ามเปิด hover ด้วยการแตะ
   เมาส์และปากกาต้องทำงานเหมือนเดิม (ลากจากถาดด้วยเมาส์ก็ควรทำได้ด้วยวิธีเดียวกัน)
2. **ภาพตัวอย่างแนวนอนบนมือถือ:** ให้ใหญ่พอดูรายละเอียดออก (เช่น กว้างเท่าที่คอลัมน์ข้างกระดานเหลือ) โดยไม่บังกระดาน ไม่บังปุ่ม ไม่ทำให้กระดานเล็กลงจนชิ้นเล็กกว่าเดิม ไม่เลื่อนหน้า
   วัดที่ 568×320, 667×375, 740×360, 844×390, 932×430 แล้วบอกขนาดก่อน/หลัง
3. ปุ่มถาดสี/เครื่องมือยัง ≥64px · motion ตามข้อ 2.1

## ทดสอบ
- เพิ่มกรณีใน `scripts/check-art-browser.mjs`: **สัมผัสจริง** (ใช้ CDP `Input.dispatchTouchEvent` touchStart/Move/End หรือ context `hasTouch: true` ไม่ใช่แค่ mouse) — กดที่หลุมสี ลากผ่านพื้นที่ว่างเข้าภาพ ต้องเห็นพู่กันตามนิ้วระหว่างทาง (ตำแหน่งพู่กันเปลี่ยนตามจุด move) และมีสีลงชิ้นที่นิ้วเข้าไปถึง สีไม่ล้น
- กรณีเดิมทั้งหมดต้องผ่าน (`npm run verify` + check-art-browser)
- ภาพหน้าจอ: ระหว่างลาก (พู่กันอยู่กลางทาง) และหลังระบาย ที่ 844×390 + ภาพตัวอย่างก่อน/หลังทุกขนาดข้างบน ใน `output/art-fix-1/`
- ปิด server ลบ `debug.log`
