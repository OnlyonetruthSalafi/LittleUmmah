## เจ้าของโปรเจกต์สั่ง (8 พ.ย. 2026)
"หัวข้อโซนทำแบบ sticker แทนการ์ดสีขาว เอาการ์ด coming soon ออกด้วย ล็อกเป็นกุญแจแทน เมื่อคลิกมีแจ้งเตือน"

1. **หัวข้อโซน "เกาะเรียนรู้" และ "เกาะผจญภัย"** — ลบพื้นการ์ด/ขอบ/เงากล่องขาว → ตัวหนังสือ sticker ชุดเดียวกับป้ายชื่อเกาะ (ขอบขาวหนา paint-order + เงานูนเล็ก ไม่ blur) ใหญ่กว่าชื่อเกาะชัดเจน
   ยังเป็น `<h2>` จริง ชื่ออังกฤษรองตัวเล็ก · contrast ≥ 4.5:1 กับขอบขาว
2. **เกาะที่ยังไม่เปิด (comingSoon: ตัจวีด, ฝึกอ่านอัลกุรอาน, เรียนรู้อิสลามพื้นฐานฯ, ตัวเลขและคณิต)**
   - ลบป้าย/ริบบิ้น "เร็วๆ นี้ / Coming soon" ออก → **ไอคอนกุญแจล็อก** (inline SVG เขียนเองใน `src/components/icons/` ตามข้อ 3, สีทอง/น้ำเงินเข้าชุด ขอบขาว) วางมุมบนของภาพเกาะ ขนาดเห็นชัดบนมือถือ (~32–40px)
     ภาพเกาะไม่ต้องทำจางมาก (อาจลด saturation เล็กน้อยได้) — ต้องยังสวย
   - เกาะเป็น `<button type="button">` (ไม่ใช่ลิงก์) มี `aria-label` เช่น "ตัจวีดพื้นฐาน — ยังไม่เปิด เร็วๆ นี้"; กุญแจเป็น `aria-hidden`
   - **กดแล้วมีแจ้งเตือน:** toast/bubble ในหน้า (ห้าม `alert()`/`confirm()`) ข้อความไทยนำ เช่น "เกาะนี้ยังไม่เปิดนะ ครูกำลังเตรียมอยู่ เร็วๆ นี้!" + อังกฤษรองเฉพาะหน้าไทยตามกฎสองภาษา
     ประกาศ screen reader ด้วย `role="status"`/`aria-live="polite"` · หายเองใน ~3 วินาที หรือกดปิดได้ (ปุ่มปิด ≥ 48px) · ไม่ดันเลย์เอาต์ · ใต้ `prefers-reduced-motion` ไม่มี animation เลื่อน/เด้ง
     ถ้ามีระบบเสียงหุ่นยนต์/`speak()` ที่หน้าแรกใช้อยู่และมีคลิปเสียงที่เหมาะอยู่แล้ว ใช้ได้ แต่ **ห้ามอัดเสียงใหม่** (ข้อความเท่านั้นพอ)
   - กุญแจกระดิกสั้นๆ ตอนกดได้ (motion-safe เท่านั้น) · hover ตามข้อ 2.1 (ขยับเฉพาะภาพ)
3. เกณฑ์เดิมยังบังคับ: ไม่เลื่อนแนวนอน, ≥64px, focus ring ชัด, `npm run verify` ผ่าน, สคริปต์ตรวจหน้าแรกอัปเดต (ตรวจว่ากดเกาะล็อกแล้ว toast ขึ้นและไม่เปลี่ยนหน้า)
