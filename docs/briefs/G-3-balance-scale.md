# G-3 — เกมใหม่: ตาชั่งสมดุล (balance-scale, 7+ ปี)
**model `gpt-6-astra` (medium) · timeout 16200 · worktree `D:/Littleummah-g3` · พอร์ต 3133**
อ่าน `D:/Littleummah/docs/briefs/G-common.md` ก่อน — **ยกเว้น: worktree นี้เริ่มจากสถานะรวมงานล่าสุด (มีเกม coin-box และ bead-lacing แล้ว)** ไฟล์ staged ตอนเริ่มคืองานรวมเดิม ห้าม reset/unstage/commit
ใช้ coin-box และ bead-lacing เป็นแบบเรื่องโครงไฟล์ หัวเกม (GameShell) พื้นหลัง ระบบเสียง และสคริปต์ตรวจ — **หัวเกม/แถบด่าน/ปุ่มต้องเหมือนเกมเดิม ห้าม CSS override ที่ทำให้หัวต่างจากเกมอื่น** (บทเรียนจาก G-1 fix1)

## การเล่น
- ตาชั่งสองแขนบนเกาะ 2.5D แขนเอียงตามน้ำหนักจริง (แอนิเมชันเอียงช้าๆ ~300ms, ปิดได้เมื่อ `prefers-reduced-motion`) แสดงสถานะเป็น **ข้อความและรูปทรง** ด้วย ("ซ้ายหนักกว่า / เท่ากันแล้ว") ไม่ใช้สีอย่างเดียว
- ของที่ใช้ชั่ง: บล็อกไม้/ลูกบาศก์ทอง-ฟ้าที่มี **จุดบอกน้ำหนัก** (1–3 จุด) + ผลไม้/สิ่งของ (แอปเปิล ส้ม แตงโม ฟักทอง ตะกร้า หนังสือ) — **สิ่งของ/พืชเท่านั้น ห้ามสัตว์ คน**
- ด่าน 1: ฝั่งซ้ายมีของ 1 ชิ้น เด็กลากบล็อกน้ำหนัก 1 ลงฝั่งขวาจนเท่ากัน (นับบล็อก)
- ด่าน 2: บล็อกน้ำหนัก 1 และ 2 ปนกัน ต้องเลือกให้ผลรวมเท่ากัน (มีหลายคำตอบที่ถูก รับได้ทุกคำตอบ)
- ด่าน 3: เปรียบเทียบ — "อะไรหนักกว่า?" วางของสองชิ้นแล้วเด็กเลือกฝั่งที่หนักกว่า/เท่ากัน สลับกับโจทย์ทำให้สมดุล
- ด่านละ 3 รอบ สุ่มโจทย์ไม่ซ้ำติดกัน, เอาของออกได้ (แตะของบนจานแล้วกลับถาด), ปุ่มเริ่มรอบใหม่, ใช้คีย์บอร์ดเล่นได้ครบ
- เสียงหุ่นเดิม: วิธีเล่น, "ซ้ายหนักกว่า", "ขวาหนักกว่า", "เท่ากันแล้ว เก่งมาก", ชวนลองใหม่ (ไม่ดุ) — ใช้สคริปต์เสียงเดิม
- ดาว: `starsPerLevel: 1` ตามระบบเดิม

## ภาพ (imagegen) — ทำภาพก่อนเขียนโค้ด
- เกาะ 2.5D มุมเฉียงแบบเกมเดิม มีฐานตาชั่ง (ตาชั่งแยกชิ้น: ฐาน, คาน, จานสองข้าง เป็น PNG โปร่งใส เพื่อหมุนคานด้วยโค้ด)
- ของที่ชั่งแยกชิ้นโปร่งใส สไตล์ 3D เด็ก palette ฟ้า เทอร์ควอยซ์ ขาว ทอง — **ไม่มีตัวหนังสือ ตัวเลข หน้าคน/สัตว์ในภาพ** (จุดน้ำหนักวาดด้วยโค้ด)
- ภาพการ์ด hub `public/games/hub/balance-scale.webp`
- ทำตัวเลือกเกาะ 2–3 แบบใน `output/g-3/options/` แล้วเลือกเองพร้อมเหตุผล (Claude ตรวจภาพอีกรอบ) · scan alpha ทุกภาพ (ภาพ imagegen อาจโปร่งแสงบางส่วน)
