Claude ดู `output/g-3/shots/` แล้วพบ:
1. **จานไม่ขยับตามคาน** (`1280x720-tilted.png`) — คานเอียงแต่จานสองข้างอยู่ที่เดิม เชือกจึงเอียงแปลกๆ ของไม่ขยับขึ้นลง เด็กจะไม่เห็นว่าฝั่งไหนหนัก
   ให้จาน (และของบนจาน + เชือก) เลื่อนขึ้น/ลงตามปลายคานจริง จานยังตั้งตรง (ไม่หมุนตามคาน) · reduced-motion ยังแสดงตำแหน่งสุดท้ายแบบไม่มีแอนิเมชัน
   จุดที่ลากวางได้ (drop target) ต้องตามจานไปด้วย
2. **ป้ายชื่อของทับขอบจาน** — "ฟักทอง Pumpkin 2 หน่วย" ซ้อนกับขอบจานและคร่อมตัวของ ส่วนป้าย "จานซ้าย / จานขวา" อยู่สูงไม่เท่ากันและลอยใต้เกาะ
   จัดป้ายให้อ่านง่าย ไม่ทับภาพ อยู่ตำแหน่งสอดคล้องกันทั้งสองฝั่ง ทุกขนาดจอ (ตรวจ 360×780 ด้วย — ตอนนี้ป้ายเบียดขอบจาน)
3. **ข้อความบนพื้นหลังภาพ** — "ลากบล็อกลงจานขวา…" และ "น้ำหนักสมมติในเกม" ที่ 1280×720 วางบนภาพพื้นหลังตรงๆ อ่านยาก ให้อยู่บนพื้นทึบ/กึ่งทึบ และวัด contrast ≥ 4.5:1
4. **ภาพการ์ด hub** `output/g-3/options/hub.png` มีขอบสีแดง/เหลืองหยักรอบวัตถุ (matte จากการลบพื้น) — ตรวจ `public/games/hub/balance-scale.webp` ว่ามีขอบนี้ไหมบนพื้นการ์ดจริง ถ้ามีให้ทำ alpha ใหม่ (กัดขอบ/defringe) ตรวจภาพแยกชิ้นอื่นด้วยแบบเดียวกัน
5. ลบ `debug.log` ที่หลุดเข้ามาใน worktree
