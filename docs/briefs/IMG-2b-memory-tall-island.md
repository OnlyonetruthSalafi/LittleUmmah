## ผลรอบแรก
Claude เลือก **ตัวเลือก A** (`island-mobile-a.png`) ใช้กับด่าน 1–2 บนมือถือแนวตั้ง
แต่ด่าน 3 มีการ์ด 16 ใบ ถึงจะจัดเป็น 4×4 การ์ดก็ยังได้แค่ราว 47–57px ซึ่งต่ำกว่า 64px

## งาน
1. สร้างเกาะ **ทรงสูง** แบบเดียวกับตัวเลือก A (ดีไซน์ สี และของประดับต้องเข้าชุดกัน ใช้ A เป็นภาพอ้างอิง)
   ให้ผิวครีมเกือบเป็นสี่เหลี่ยมจัตุรัส และ **ใหญ่พอวางการ์ด 4×4 ให้แต่ละใบ ≥64×64px** บนจอกว้าง 360px
   (เว้นช่องไฟระหว่างการ์ดตาม `memory.css` เดิม) ภาพทั้งภาพต้องไม่สูงจนต้องเลื่อนหน้า บนจอ 360×780 ที่มีแถบหัวเกม
   ผิวครีมเรียบ ไม่มีตัวหนังสือ ไม่มีคนหรือสัตว์ ใช้ PNG พื้นโปร่งใส ทำ 2 ตัวเลือก
2. วัดกรอบผิวครีมด้วยสคริปต์เดิม แล้วคำนวณขนาดการ์ด 4×4 ที่จอกว้าง 360, 390, 430px
   รวมถึงความสูงทั้งภาพเทียบกับพื้นที่ที่จอเหลือ (เอาค่าความสูงของแถบหัวเกมจากโค้ดจริง)
3. ตรวจว่าตัวเลือก A ไม่โปร่งแสงตรงตัวเกาะ แล้ว scan alpha ภาพใหม่ด้วย
4. ทำแผ่นเทียบ `contact-tall.png` และเขียนผลเพิ่มใน `report.md`
