# G-1 — เกมใหม่: กล่องเหรียญนับจำนวน (coin-box, 3–6 ปี)
**model `gpt-6-astra` (medium) · timeout 16200 · worktree `D:/Littleummah-g1` · พอร์ต 3131**
อ่าน `D:/Littleummah/docs/briefs/G-common.md` ก่อน

## การเล่น
- หุ่นนูรีบอกเลขเป้าหมาย ("ใส่เหรียญ 3 เหรียญนะ") แสดงเลขเป็น **ข้อความจริง** (ตัวเลขใหญ่ + จุดนับกำกับ ไม่ใช่สีอย่างเดียว)
- เด็กลากเหรียญทีละเหรียญจากถาดลงช่องหยอดของกล่อง ทุกเหรียญที่ลงหุ่นนับออกเสียง "หนึ่ง สอง สาม…" และตัวนับบนจอเพิ่มขึ้น
- ครบแล้วกดปุ่ม "ครบแล้ว" (หรือครบพอดีแล้วจบรอบเอง — เลือกแบบที่เด็ก 3 ขวบไม่สับสนและอธิบายในรายงาน) ใส่เกินให้หุ่นชวนนับใหม่อย่างนุ่มนวล มีปุ่มเอาเหรียญออก/เริ่มรอบใหม่
- 3 ด่าน: เลข 1–3, 1–5, 1–10 ด่านละ 3 รอบ (สุ่มเลขไม่ซ้ำติดกัน)
- เสียงนับเลขไทย 1–10 + บทวิธีเล่น/ชม/ชวนลองใหม่ เป็นเสียงหุ่นเดิม

## ภาพ (imagegen)
- เกาะ 2.5D มีกล่องเหรียญ/หีบสมบัติสีทอง-ฟ้าพร้อมช่องหยอดด้านบน (กล่องแยกเป็นชิ้นโปร่งใสได้ถ้าจำเป็นต่อการทำแอนิเมชัน)
- เหรียญทองแยกชิ้นโปร่งใส ลายดาว/เรขาคณิต **ไม่มีรูปคน สัตว์ ตัวหนังสือ ตัวเลข หรือเหรียญเงินจริงของประเทศใด** และ **ห้ามกระปุกออมสินรูปหมู/สัตว์**
- ถาดใส่เหรียญ, ภาพการ์ด hub `public/games/hub/coin-box.webp`
- ทำตัวเลือกเกาะ 2–3 แบบใน `output/g-1/options/` แล้วเลือกเองพร้อมเหตุผล (Claude ตรวจภาพอีกรอบ)
