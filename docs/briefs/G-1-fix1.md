Claude ดู `output/g-1/shots/` เทียบกับเกม `bead-lacing` (G-2) และเกมเดิม เช่น shape-match แล้วพบ:
1. **หัวเกมไม่เหมือนเกมอื่น** — ที่ 844×390 และ 1280×720 ชื่อเกม "กล่องเหรียญนับจำนวน" ถูกบีบเป็นคอลัมน์แคบข้างปุ่มกลับ ตัวหนังสือเล็กมาก
   ให้ใช้หัวเกม/แถบด่าน/ปุ่มเสียงแบบเดียวกับเกมเดิมใน `GameShell` (ปุ่ม "รวมเกม Game Hub", "เสียงเปิด Sound on" ที่จอกว้าง) ห้ามมี CSS override ที่ทำให้หัวต่างจากเกมอื่น
2. **พื้นหลัง** — เกมอื่นมีฉากพื้นหลังเกาะเกม (`public/games/hub/game-hub-bg.webp` หรือที่ GameShell ใช้) แต่ G-1 เป็นสีฟ้าเรียบ ให้ใช้ระบบพื้นหลังเดียวกับเกมเดิม
3. **ปุ่ม "เอาออก 1 เหรียญ / Take one out"** ข้อความล้นปุ่มที่ 844×390 (ขึ้น 4 บรรทัด) และปุ่มล่างที่ 1280 ตัวเล็ก/ลอยห่างจากเกาะ — จัดกลุ่มปุ่มให้อ่านได้ทุกจอ ข้อความไม่ล้น ปุ่ม ≥64px
4. **ถาดเหรียญเห็นเหรียญเดียว** — เด็กควรเห็นกองเหรียญที่หยิบได้ (เช่น 3–5 เหรียญซ้อนกันในถาด หรือแถวเหรียญ) เพื่อให้รู้ว่าหยิบได้หลายครั้ง ยังคงลากทีละเหรียญ
5. ที่ 1280×720 เกาะเล็กและมีที่ว่างมาก ส่วนแผงคำสั่งอยู่มุมขวาบนตัวเล็ก — จัดให้สมดุลแบบเกมเดิม (เกาะใหญ่ขึ้น แผงคำสั่งอ่านง่าย)
6. ถ้า review ของ Codex (`D:/Littleummah/output/codex/G-1-review.md`) มีข้อที่ยังไม่ได้แก้ ให้แก้ด้วย
