# G-2 — เกมใหม่: ร้อยเชือกลูกปัด (bead-lacing, 3–6 ปี)
**model `gpt-6-astra` (medium) · timeout 16200 · worktree `D:/Littleummah-g2` · พอร์ต 3132**
อ่าน `D:/Littleummah/docs/briefs/G-common.md` ก่อน

## การเล่น
- บนเกาะมีเชือกร้อยลูกปัดขึงอยู่ และ **การ์ดแบบ** แสดงลำดับลูกปัดที่ต้องร้อย (สี + รูปทรง เช่น กลม เหลี่ยม ดาว — ห้ามสื่อด้วยสีอย่างเดียว)
- เด็กลากลูกปัดจากถาดไปที่ปลายเชือก ลูกปัดเลื่อนเข้าไปเรียงต่อกัน ถ้าไม่ตรงแบบ ลูกปัดเด้งกลับถาดและหุ่นบอกใบ้ (ชี้ช่องถัดไปบนการ์ดแบบ)
- 3 ด่าน: ร้อยตามแบบ 3 เม็ด → ตามแบบ 5 เม็ด → **ต่อแบบซ้ำ** (AB AB / ABC ABC เติม 2–3 เม็ดท้าย) ด่านละ 3 รอบ
- เสียงหุ่น: วิธีเล่น ชม ใบ้ (บอกชื่อสีและรูปทรงเป็นภาษาไทย)

## ภาพ (imagegen)
- เกาะ 2.5D ที่มีแท่น/โต๊ะไม้สำหรับขึงเชือก (เชือกและปลายเข็มพลาสติกวาดเป็นชิ้นแยกหรือวาดด้วยโค้ด เลือกที่วางพิกัดลูกปัดได้แม่นกว่า)
- ลูกปัดแยกชิ้นโปร่งใส อย่างน้อย 4 สี × 3 รูปทรง (สีตาม palette ฟ้า เทอร์ควอยซ์ ทอง ขาว + สีรองที่แยกกันชัด) ไม่มีหน้า/ตัวหนังสือ
- ถาดลูกปัด, ภาพการ์ด hub `public/games/hub/bead-lacing.webp`
- ทำตัวเลือกเกาะ 2–3 แบบใน `output/g-2/options/` แล้วเลือกเองพร้อมเหตุผล (Claude ตรวจภาพอีกรอบ)
