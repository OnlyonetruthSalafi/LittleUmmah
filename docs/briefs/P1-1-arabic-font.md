## ปัญหา
`src/features/arabic/classroom.css` เรียก `var(--font-arabic)` แต่ไม่มีที่ไหนกำหนดค่า `src/app/fonts.ts` โหลดแค่ Baloo 2 + Noto Sans Thai Looped

## ผู้ใช้คือเด็กเล็ก 3–6 ปี (และ 7+) ที่เพิ่งหัดอ่านอักษรอาหรับ — เกณฑ์เลือกฟอนต์
1. **รูปอักษรแบบหัดอ่าน (Naskh ตัวพิมพ์มาตรฐาน)** ตรงกับหนังสือเรียนอิกเราะอ์/กออิดะฮ์ที่เด็กเห็น — ไม่เอาแบบประดิษฐ์ ตัวเขียนมือ Kufi เรขาคณิต หรือ Ruq'ah
2. **จุดชัด แยกจากตัวอักษร** (ب ت ث / ج ح خ / ف ق) และ **ฮะเราะกาต (فتحة كسرة ضمة سكون شدة تنوين)** ใหญ่ วางตรงตำแหน่ง ไม่ชนกัน ไม่ทับจุด
3. **ตัวอักษรเดี่ยวขนาดใหญ่** (ห้องเรียนอักษร) ต้องดูเป็นมิตร เข้ากับ Baloo 2 ตัวอ้วนมนของเว็บ แต่ไม่เสียรูปที่ถูกต้อง
4. รองรับ **ข้อความยาวมีฮะเราะกาตครบ** (ดุอาอ์ ซิกรุ ตัวบทฟัตวาในหน้าผู้ปกครอง) และสัญลักษณ์ ﷺ / «» ถ้าฟอนต์ไม่มี ﷺ ให้รายงาน
5. ขนาดไฟล์เล็กพอสำหรับมือถือ 4G — โหลดเฉพาะ `subsets: ["arabic"]` และน้ำหนักที่ใช้จริง, `display: "swap"`
6. สัญญาอนุญาต OFL (Google Fonts) — ยืนยันใน metadata ของฟอนต์

## งาน
1. **ยืนยันชื่อฟอนต์มีจริงใน** `node_modules/next/dist/compiled/@next/font/dist/google/font-data.json` ก่อนใช้ (เคยพลาดกับ Baloo Thai 2)
   ผู้สมัครอย่างน้อย: **Noto Naskh Arabic**, **Scheherazade New**, **Baloo Bhaijaan 2**, **Amiri**, **Noto Sans Arabic** และตัวอื่นที่คุณเห็นว่าเข้าเกณฑ์
2. **หาทุกจุดที่แสดงตัวอาหรับ** (grep ตัวอักษรช่วง U+0600–U+06FF, `lang="ar"`, `dir="rtl"`, `--font-arabic`) แล้วจัดเป็นสองบทบาท
   - **ตัวอักษรเดี่ยว/คำสั้นขนาดใหญ่** (ห้องเรียนอักษร, เกมจับคู่อักษร)
   - **ข้อความมีฮะเราะกาต** (ดุอาอ์, ซิกรุ, ตัวบทหน้าผู้ปกครอง)
   ถ้าฟอนต์เดียวดีพอทั้งสองบทบาท ใช้ฟอนต์เดียว (โหลดน้อยกว่า) ถ้าไม่ เสนอสองตัว (`--font-arabic` + `--font-arabic-display`)
3. **ทำแผ่นเทียบ** `output/p1-1-arabic-font/compare.html` + ภาพ PNG ต่อผู้สมัคร:
   ตัวอักษรเดี่ยว 28 ตัวขนาดใหญ่ · รูปต้น/กลาง/ท้ายของ ب ج ع ه · كَتَبَ · مُحَمَّدٌ · بِسْمِ اللَّهِ · ดุอาอ์จริงหนึ่งบทจากในเว็บ · ﷺ
   วัดขนาดไฟล์ woff2 ที่ next/font สร้างต่อฟอนต์ (ดูจาก `.next/static/media` หลัง build)
   **ภาพเทียบห้ามมีภาพสิ่งมีชีวิต** ใช้ข้อความล้วน
4. **ติดตั้งตัวที่คุณแนะนำ** ใน `src/app/fonts.ts` → เพิ่มใน `fontClasses` → กำหนด `--font-arabic` ใน `@theme` ของ `src/app/globals.css`
   และใส่ fallback (`serif` หรือ `system-ui`) ให้ทุกจุดที่ใช้ตัวอาหรับใช้ตัวแปรนี้ เขียนให้เปลี่ยนฟอนต์ได้ในบรรทัดเดียว
   (เจ้าของโปรเจกต์จะเลือกจากแผ่นเทียบ — ข้อ D2 ในแผน)
   `global-not-found.tsx` ใช้ `fontClasses` เดียวกัน ตรวจว่ายังทำงาน
5. ตรวจหน้า **ไทยไม่เปลี่ยน**: ตัวไทย/ละตินยังใช้ฟอนต์เดิม (computed style) และ layout ห้องเรียนอักษรไม่ล้น/ไม่ตัดฮะเราะกาต
   (ฟอนต์อาหรับบางตัวมี ascent/descent สูง → `line-height` อาจต้องปรับเฉพาะ element อาหรับ ให้รายงานจุดที่ปรับ)

## เกณฑ์ผ่าน
- `npm run verify` ผ่าน
- computed `font-family` ของตัวอาหรับในห้องเรียนอักษร เกมจับคู่อักษร ดุอาอ์ และหน้าผู้ปกครอง = ฟอนต์ที่โหลด (แปะผลวัดใน report)
