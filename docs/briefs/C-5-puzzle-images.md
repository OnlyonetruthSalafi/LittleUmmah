อ่าน `D:/Littleummah/docs/briefs/_content-common.md` ก่อน และ `CODEX_PUZZLE_BRIEF.md` ที่รากโปรเจกต์

## บริบท
จิ๊กซอว์ 2.5D (`src/features/games/data/puzzleArt.ts`, `presentation.ts`, บอร์ดจิ๊กซอว์) วางภาพด่านลงถาดด้วย homography (`TRAY`) มีข้อยกเว้นขนาดช่องบนมือถือ (AGENTS ข้อ 2) ห้ามแตะ `TRAY`/ภาพเกาะ

## งาน
- สร้างภาพด่านใหม่ 3 ภาพ (สัดส่วน/ขนาดตามภาพด่านเดิม): สวนกระถางดอกไม้, เรือใบในอ่าว, สถานีรถไฟของเล่น — **ไม่มีคน สัตว์ ตัวหนังสือ**
  ภาพต้องอ่านง่ายเมื่อตัดเป็น 4/6/9 ชิ้น (แต่ละส่วนของภาพมีจุดสังเกตต่างกัน)
- ให้ภาพใหม่ถูกเล่นจริง: เป็นชุดภาพสลับต่อรอบ/เลือกภาพในกระดานเดิม (ปุ่ม ≥64px ไทยนำ) โดยภาพเดิมยังเล่นได้และความก้าวหน้า/ดาวไม่ปะปน
- ภาพเข้า optimize pipeline + sha256 ตามแบบเดิม

## เกณฑ์ผ่าน
- `tests/puzzle-art.test.mjs` ครอบคลุมภาพใหม่ · `scripts/check-puzzle-browser.mjs` ผ่านทุกภาพ ทุกด่าน ทุกขนาดจอในสคริปต์ (ตัดชิ้น/ลงช่องถูก)
- ภาพหน้าจอภาพใหม่ทุกภาพที่ 360×844 และ 1536×770
