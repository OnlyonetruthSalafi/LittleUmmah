## งาน
1. **`/parents/curriculum` — ภาพรวมหลักสูตร**
   แยกตามวัย (3–6 / 7+) แล้วตามเกาะที่เปิดใช้งาน: ชื่อเกาะ, จำนวนบท/เล่ม/ด่าน, รายชื่อบท (ชื่อบทตามข้อมูลจริง), ลิงก์ไปเกาะ
   ดึงจากข้อมูลจริง (`src/lib/lessons.ts`, data ของ moral/explore/faith/stories/hadith/games/arabic/languages/art — หาเอง) **เป็น server component** ไม่ hardcode รายชื่อ เพื่อให้เพิ่มบทแล้วหน้าตามเอง
   เกาะ/บทที่ยังไม่เปิด (ready=false, "เร็วๆ นี้") ไม่ต้องแสดง หรือแสดงแค่ว่า "เร็วๆ นี้" โดยไม่แสดงรายละเอียด
   ยาวมากบนมือถือได้ — ใช้ `<details>` ต่อเกาะ (เปิดได้ด้วยแป้นพิมพ์, ไม่มี motion ที่ผิดข้อ 2.1)
2. **`/parents/progress` — ลูกเรียนอะไรไปแล้ว**
   client component อ่าน localStorage ที่มีอยู่แล้วผ่าน store/ฟังก์ชันเดิมของแต่ละ feature (`moral/progress.ts`, `games/engine/progress.ts`, `learning-stars/store.ts`, faith/explore progress, Arabic `Classroom` letters ฯลฯ) — **อ่านอย่างเดียว ห้ามเขียน**
   แสดงต่อเกาะ: บทที่ได้ดาว/ฝึกแล้ว (ชื่อบท + วันที่ฝึกถ้ามี), ด่านเกมที่ผ่าน + ดาว, อักษรที่เรียนแล้ว, ดาวเรียนรู้คงเหลือและเวลาเล่นวันนี้
   ไม่มีข้อมูล → ข้อความอธิบายว่าข้อมูลอยู่เฉพาะในเบราว์เซอร์เครื่องนี้ (ไม่ใช่ error)
   SSR ไม่รู้ localStorage: ห้าม hydration mismatch — ใช้ `useSyncExternalStore` หรือ pattern เดิม, CLS ต่ำ (จองพื้นที่/skeleton ได้เพราะเป็นหน้าผู้ใหญ่)
   ไม่ต้องอยู่หลัง ParentGate เว้นแต่หน้าผู้ปกครองอื่นใช้ gate อยู่แล้ว (ตรวจแล้วทำให้เหมือนกัน เขียนเหตุผลในรายงาน)
3. **`/parents/privacy` — นโยบายความเป็นส่วนตัวเป็นหน้าของตัวเอง**
   ย้ายเนื้อหาหัวข้อ "ข้อมูลส่วนตัว" ใน `content.ts` มาเป็นแกน (คงถ้อยคำเดิมให้มากที่สุด รวมย่อหน้า Freemium) จัดเป็นหัวข้อย่อย: สิ่งที่เว็บไม่ทำ, สิ่งที่เว็บจำไว้ในเครื่อง (ตาราง key → ความหมาย ครบทุก key ที่ grep เจอใน `src`), ข้อมูลทางเทคนิคของผู้ให้บริการเซิร์ฟเวอร์ (เว็บ host บน Vercel — ตรวจ `next.config.ts`/เอกสาร deploy ก่อนเขียน), เสียงสังเคราะห์ของเครื่อง (ตรวจโค้ด `speech.ts` ว่าเรียก `speechSynthesis` เมื่อไร แล้วเขียนตามจริงว่าบางเบราว์เซอร์อาจใช้บริการเสียงออนไลน์ของผู้ผลิตเบราว์เซอร์), วิธีลบข้อมูล (ปุ่มล้างความคืบหน้า — วาง `ClearProgress` ในหน้านี้ด้วย)
   มีบรรทัด "ปรับปรุงล่าสุด" เป็นวันที่ (ค่าคงที่ใน content แก้มือ)
   ไม่มีส่วนผู้รับผิดชอบ/ช่องทางติดต่อ (ดูกติกาข้างบน)
4. **`/parents/sponsors` — ผู้สนับสนุน**
   สั้น: ขอบคุณ Shuhada ที่สนับสนุนให้เว็บนี้ใช้ได้ฟรี + โลโก้เดิมที่ Footer ใช้ (ไม่ใช่ลิงก์) + หลักการของ **เว็บ** ที่เป็นจริงแล้ว (ไม่มีโฆษณา ไม่มีลิงก์ซื้อของในพื้นที่เด็ก ไม่ติดตามเด็ก) เขียนเป็นหลักการของเว็บ ไม่ใช่ข้อตกลงของผู้สนับสนุน
   ไม่ต้องทำซ้ำย่อหน้า Freemium — ลิงก์ไปหน้า privacy แทน
5. **หน้า `/parents`** — เพิ่มลิงก์ไปสี่หน้าใหม่ในแถบลิงก์ด้านบน (`.ui-pill` ≥48px) และย่อหัวข้อ "ข้อมูลส่วนตัว" เหลือสรุปสองบรรทัดพร้อมลิงก์ไป `/parents/privacy` (แบบเดียวกับที่ทำกับหลักฐาน 10 พ.ย.) — ห้ามแก้ถ้อยคำหัวข้ออื่น
   Footer: ถ้ามีลิงก์ผู้ปกครองอยู่แล้ว เพิ่มลิงก์ privacy ได้ (ฝั่งผู้ปกครองเท่านั้น ไม่ใช่ลิงก์ผู้สนับสนุน)
6. metadata/SEO ของหน้าใหม่ใช้ `pageMetadata` เหมือนหน้าเดิม, sitemap ถ้ามี (`src/app/sitemap.ts` — ตรวจ), `/en` ทำงานด้วย (ยัง noindex ตามเดิม)
