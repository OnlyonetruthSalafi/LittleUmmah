# กติการ่วมของงานเกมใหม่ G-* (8 พ.ย. 2026)

อ่าน `D:/Littleummah/docs/briefs/_content-common.md` ก่อน (กติกาเดียวกันทุกข้อ) ยกเว้น:
- **worktree เริ่มจากสถานะรวมงานล่าสุด (ไม่ใช่ 197aae4)** ไฟล์ที่เห็นเป็น staged ตอนเริ่มคืองานรวมเดิม ห้าม reset/unstage
- เกมนี้มีอยู่แล้วเป็น **การ์ด "เร็วๆ นี้"** ใน `src/features/games/data/comingSoon.ts` — งานคือทำให้เล่นได้จริงแล้วย้ายออกจากรายการนั้นเข้า `catalog.ts`

## แบบที่ต้องตาม
- อ่าน `GAME_SYSTEM_PLAN.md` และดูเกมที่มีอยู่เป็นแบบ: `ShapeBoard.tsx` + `shape.css` + `data/shapeArt.ts` (ลากวางบนเกาะ 2.5D),
  `SequenceBoard.tsx` (ของเรียงใต้เกาะบนมือถือ), `GameShell` / `GameIntro` / `GameTutorial` / `gameTutorials.ts`, `presentation.ts`, ระบบดาวเรียนรู้ (1 ดาวต่อด่านที่ผ่าน)
- ใช้ engine ลาก/เสียง/ผลลัพธ์ของระบบเกมเดิมทั้งหมด ห้ามสร้างระบบคู่ขนาน
- เกาะเป็นภาพ 2.5D มุมกล้องเฉียงแบบเกาะเกมเดิม (สไตล์เดียวกับ `public/games/hub/*.webp`) ของที่ลากได้เป็น **WebP โปร่งใสแยกชิ้น** วางด้วยพิกัดที่วัดจากภาพด้วยสคริปต์ (ห้ามกะ)
- การ์ดในหน้าเกาะเกมใช้ภาพ `public/games/hub/<slug>.webp` สไตล์เดียวกับการ์ดเดิม
- เสียงพากย์หุ่น (บอกวิธีเล่น ชมเมื่อถูก ชวนลองใหม่) ผ่าน pipeline เสียงหุ่นเดิม; sfx ใช้ไฟล์ที่มีใน `public/audio/sfx/` เท่านั้น ห้ามดนตรี
- ปุ่มและของที่เด็กลาก ≥ 64px ทุกขนาดจอ ถ้าทำไม่ได้จริงให้รายงานตัวเลข **ห้ามเขียนข้อยกเว้นใหม่ลง AGENTS.md เอง**
- ต้องเล่นได้ทั้ง 360×780, 390×844, 844×390 (มือถือแนวนอน), 768×1024, 1280×720 ไม่เลื่อนหน้า ไม่มีของล้นเกาะ, ใช้นิ้วลากได้ (hasTouch) และใช้แป้นพิมพ์ได้แบบเกมเดิม
- เพิ่ม `scripts/check-<slug>-browser.mjs` (เล่นจนจบทุกด่าน วัดขนาด ลากด้วย touch, ตรวจภาพโหลดช้า) และ unit test ของตรรกะเกม

## ฉากเกมต้องตรงกับภาพเกาะหน้าเกม (เจ้าของโปรเจกต์สั่ง 8 พ.ย. 2026) — บังคับทุกเกม
ภาพ `public/games/hub/<slug>.webp` คือคอนเซปต์แรกของเกม **ฉากเล่นจริงต้องเป็นเกาะเดียวกัน ของประกอบชุดเดียวกัน มุมกล้องเดียวกัน และอลังการเท่าภาพเกาะ**
- ทำแบบเกมหยอดรูปทรง: แยกชิ้นจากภาพเกาะ (หรือ gen ใหม่โดยใช้ภาพเกาะเป็นภาพอ้างอิง) ให้เกาะ พื้นผิว ขอบทอง ต้นไม้ ของตกแต่ง เหมือนภาพหน้าเกม
- ของที่เด็กเล่นต้องเป็นวัตถุ 3D แบบในภาพเกาะ ไม่ใช่ UI แบน: เชือกเป็นเชือกจริงมีลายเกลียว (ไม่ใช่เส้นประ), ลูกปัดเป็นลูกปัด 3D มีรู (ไม่ใช่ปุ่มกลม), ช่องหยอดเป็นช่องในภาพ (ไม่ใช่กรอบเส้นประ)
- ถาด/ของที่รอเล่นวางอยู่บนเกาะหรือในถาดที่อยู่ในภาพ ไม่ลอยเป็นแผง UI แยก (ป้ายข้อความเล็กๆ กำกับได้ แต่ฉากต้องนำ)
- ส่งภาพเทียบ **ภาพเกาะหน้าเกม vs ฉากเล่นจริง** วางคู่กันทุกขนาดจอ — Claude ตีกลับถ้าดูไม่เป็นเกาะเดียวกัน
