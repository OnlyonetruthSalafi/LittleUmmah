# VIS-1 — ร้อยลูกปัด: ทำฉากเล่นให้เหมือนภาพเกาะหน้าเกม
**model `gpt-6-astra` (medium) · timeout 14400 · worktree `D:/Littleummah-vis1` · พอร์ต 3141**
อ่าน `D:/Littleummah/docs/briefs/G-common.md` (โดยเฉพาะหัวข้อสุดท้าย "ฉากเกมต้องตรงกับภาพเกาะหน้าเกม") · worktree เริ่มจากชุดรวมงานล่าสุด ไฟล์ staged ตอนเริ่มคืองานรวมเดิม ห้าม reset/unstage/commit

## ปัญหา (เจ้าของโปรเจกต์ลองเล่นแล้ว 8 พ.ย. 2026)
"ตัวเกมจริงกับเกาะและหน้าแนะนำไม่ตรงกัน เกมต้องอลังการใกล้เคียงกับเกาะด้านหน้ามากที่สุด"
ภาพเป้าหมาย: `public/games/hub/bead-lacing.webp` (ต้นฉบับใหญ่ใน `output/` หรือ `scripts/source-images.json` ถ้ามี) —
เกาะหญ้าเทอร์ควอยซ์ ฐานหินขาวมีลายเพชรทองฝัง, ม้านั่งไม้มีมุมทองและแผ่นเทอร์ควอยซ์, **เชือกจริงลายเกลียวสีครีม** ร้อยลูกปัด 3D (ทรงกลมน้ำเงิน, ลูกบาศก์เทอร์ควอยซ์, ดาวทอง) ปลายมีเข็มร้อยสีเทอร์ควอยซ์, **ถาดไม้ใส่ลูกปัดอยู่บนเกาะหน้าม้านั่ง**, ดอกไม้ ใบไม้ หิน
ฉากตอนนี้: เกาะคนละแบบ ม้านั่งแบน เชือกเป็นเส้นประ ปลายเชือกเป็นกรอบเส้นประ ลูกปัดดูเป็นปุ่ม ถาดเป็นแผง UI ลอยด้านขวา → **ทำใหม่ทั้งฉาก**

## งาน
- ฉากเล่น = เกาะเดียวกับภาพหน้าเกม มุมกล้องเดียวกัน (แยกชิ้นจากภาพเกาะ หรือ gen ใหม่โดยใช้ภาพเกาะเป็น reference ให้เหมือนที่สุด) ทำเกาะแบบไม่มีลูกปัดบนเชือก เพื่อให้เด็กร้อยเอง
- เชือกวาดเป็นเชือก 3D (ภาพเชือกแยกชิ้น หรือ SVG ที่มีลายเกลียว เงา ไฮไลต์) โค้งพาดบนม้านั่งแบบในภาพ ลูกปัดที่ร้อยแล้วเรียงบนเชือกตามโค้ง มีเข็มที่ปลาย
- ลูกปัดทุกแบบเป็นภาพ 3D แยกชิ้นโปร่งใส มีรูร้อยเห็นชัด สไตล์เดียวกับในภาพเกาะ (ทรงกลม ลูกบาศก์ ดาว + ทรงที่ใช้อยู่ในโจทย์) — defringe ขอบ, scan alpha
- **ถาดลูกปัดอยู่บนเกาะ** (ถาดไม้แบบในภาพ) เป็นที่หยิบลูกปัด ถ้าบนมือถือแนวตั้งที่ไม่พอ ให้ถาดอยู่ชิดใต้เกาะแบบเกม sequence แต่ยังเป็นถาดไม้ 3D ไม่ใช่แผง UI
- แบบที่ต้องร้อยตาม (โจทย์) แสดงเป็นลูกปัด 3D เล็กบนป้ายไม้/การ์ดที่กลมกลืนกับฉาก ไม่ใช่กล่อง UI ขาวลอย
- ป้ายชื่อลูกปัดย้ายไปเป็น aria-label + ป้ายเล็กใต้ลูกปัดที่อ่านได้ (ตอนนี้บนจอ 360px ขึ้น 2–3 บรรทัดตัวเล็ก) — ชื่อต้องบอกทั้งสีและรูปทรง
- ตรรกะเกม เสียง ด่าน คีย์บอร์ด ทุกอย่างคงเดิม (unit test เดิมต้องผ่าน)

## เกณฑ์ผ่าน
- ภาพเทียบคู่ **ภาพเกาะหน้าเกม | ฉากเล่นจริง** ที่ 360×780, 844×390, 1280×720 ใน `output/vis-1/compare/` — Claude จะตัดสินจากภาพนี้
- ลูกปัด/ปุ่มที่เด็กแตะ ≥64px (ถ้าไม่ได้ให้รายงานตัวเลข) ไม่เลื่อนหน้า ไม่ล้นเกาะ · `check-bead-lacing-browser.mjs` ผ่านทุกขนาด
- `npm run verify` ผ่าน · รายงาน `output/vis-1/report.md`
