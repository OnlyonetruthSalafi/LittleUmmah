# C-3 — เกาะมารยาท: อยู่ร่วมกันกับนูรี 4 บทการ์ตูนหุ่นยนต์
**model `gpt-6-astra` (medium) · timeout 12600 · worktree `D:/Littleummah-c3` · พอร์ต 3113**
อ่าน `D:/Littleummah/docs/briefs/_content-common.md` ก่อน และอ่าน brief เก่า `CODEX_MORAL_BRIEF.md`, `CODEX_MORAL_CAST_BRIEF.md`, `CODEX_MORAL_SCENES_BRIEF.md` ที่รากโปรเจกต์

## กฎเฉพาะเกาะนี้ (เจ้าของโปรเจกต์สั่ง)
- **ตัวละครในการ์ตูนเป็นหุ่นยนต์เท่านั้น** ห้ามเด็กหรือคน แม้หันหลังหรือใบหน้าว่าง ใช้หุ่นจากแผ่นตัวละคร (cast) ที่อนุมัติแล้ว นูรีเป็นครูวางด้วยโค้ดทางขวาตามเดิม
- ภาพฉากเว้นพื้นด้านขวาให้นูรี ไม่มีตัวหนังสือในภาพ ภาพการ์ดตามขนาด/สไตล์การ์ดเดิม
- ข้อความเป็นมารยาททั่วไป ไม่ยกอายะฮ์ หะดีษ ดุอาอ์ (ถ้ามีประโยคเชิงศาสนาให้ติดป้ายตามกติการ่วม)

## งาน
เพิ่ม 4 บท (บทละ ~5 ฉาก) ด้วยระบบเดิม (`src/lib/lessons.ts`, `src/features/moral/{data,cartoon}.ts`, `scripts/make-moral-cartoon-voice.mjs`)
- kids 3–6: **รอคิว** (รอตาเล่นชิงช้า/ต่อแถว), **เก็บของเล่นหลังเล่น**
- juniors 7+: **ฟังเพื่อนพูดจนจบ**, **ดูแลของส่วนรวม** (หนังสือห้องสมุด/สนามเด็กเล่น)
- แต่ละบท: สถานการณ์ → หุ่นตัวหนึ่งทำพลาดเล็กน้อยหรือลังเล → นูรีชวนคิด → ทำสิ่งที่ดี → สรุปสั้นๆ ที่เด็กจำได้ (ไม่ดุ ไม่ทำให้อาย)
- ภาพ: การ์ด 4 + ฉากตามความจำเป็น (ใช้ซ้ำได้), เสียงพากย์ทุกบรรทัดของนูรีด้วยสคริปต์เดิม

## เกณฑ์ผ่าน
- ครบ 4 บท ขึ้นถูกวัย, เล่น-พัก-ย้อน-ปิดแล้วเสียงหยุด, ไฟล์เสียงครบตรงบท
- `scripts/check-moral-browser.mjs` ขยายให้ตรวจบทใหม่ · ภาพหน้าจอทุกฉากที่ 360×780 และ 1280×720
- ภาพ crop หัวหุ่นทุกตัวยืนยันว่าเป็นเครื่องจักรชัดเจน (ข้อ 1.2) + ผล scan alpha
