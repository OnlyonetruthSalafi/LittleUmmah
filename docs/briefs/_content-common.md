- **ศาสนา:** แพ็กเหล่านี้ไม่มีอายะฮ์ หะดีษ ดุอาอ์ หรือเรื่องศาสดา ถ้าจำเป็นต้องมีประโยคที่อ้างถึงอัลลอฮ์/ศาสนา (เช่น "อัลลอฮ์ทรงสร้าง...")
  ให้ใช้รูปแบบเดียวกับประโยคที่มีอยู่แล้วในไฟล์ข้อมูลของเกาะนั้น และ **ติดป้าย `REVIEW-RELIGIOUS` พร้อมระบุไฟล์:บรรทัด** ในรายงาน ห้ามแต่งตัวบทหรือยกหะดีษเอง
- **ภาพใหม่ (imagegen):** สไตล์ 3D การ์ตูนพรีเมียมเหมือนภาพเดิมของเกาะ, ไม่มีตัวหนังสือในภาพ, สิ่งมีชีวิตใบหน้าว่างทั้งหมด (ไม่มีตา จมูก ปาก คิ้ว แก้มแดง),
  หุ่นยนต์ใช้ดีไซน์จาก cast/ตัวละครเดิมเท่านั้น ห้ามเปลี่ยนนูรี
  ส่งพร้อมงาน: **ภาพ crop ศีรษะของสิ่งมีชีวิตทุกตัว** (`output/<id>/head-crops/`) และ **ผล scan alpha** (Codex PNG อาจโปร่งแสงบางส่วน) ภาพใหญ่เข้า `scripts/optimize-images.mjs` + sha256 ใน `scripts/source-images.json` ตามแบบเดิม
  หลัง optimize ให้ revert ภาพที่ไม่เกี่ยวที่ถูกสร้างใหม่โดยบังเอิญ
- **ภาพถ่าย:** เฉพาะ CC0/สาธารณสมบัติ ตรวจจาก metadata ต้นทาง (Commons API `extmetadata` ช้าๆ เพราะ rate-limit) ไม่มีคน ไม่มีลายน้ำ/ตัวหนังสือ ไม่มีเลือด/ล่าเหยื่อ ใส่ผู้ถ่ายในเครดิต
- **เสียงพากย์:** ใช้สคริปต์เดิม (`scripts/lib/robot-voice.mjs`, ElevenLabs เสียง Leo + ffmpeg robot filter) key อยู่ใน `.env.local` ห้ามพิมพ์ค่า key
  ใส่ใน `public/audio/th/...` ตามแบบเดิม ถ้าคำไทยออกเสียงผิด ให้ใช้วิธีเดิม (`SAY_AS_ENGLISH` / อัดใหม่ทั้งบรรทัด ห้ามตัดต่อ)
  ถ้าเรียก ElevenLabs ไม่ได้ (key/เครดิต/ffmpeg) ให้ทำส่วนอื่นให้เสร็จ เขียนรายการบรรทัดที่ยังไม่มีเสียงในรายงาน และให้ UI ทำงานได้ (ไม่พังถ้าเสียงหาย ตามพฤติกรรมเดิม)
- ห้ามดนตรี/สัญลักษณ์ดนตรี, ห้าม emoji คน/สัตว์, ปุ่มเด็ก ≥ 64px (ยกเว้นที่ AGENTS อนุมัติแล้ว), motion ตามข้อ 2.1
