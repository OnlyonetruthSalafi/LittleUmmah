# C-10 — เกมเรียงลำดับ: ชุดของใหม่
**model `gpt-6-astra` (medium) · timeout 9000 · worktree `D:/Littleummah-c10` · พอร์ต 3120**
อ่าน `D:/Littleummah/docs/briefs/_content-common.md` และ `CODEX_SEQUENCE_BRIEF.md` ที่รากโปรเจกต์ก่อน

## บริบท
เกมเรียงลำดับ (`src/features/games/data/sequence.ts`, `sequenceArt.ts`, บอร์ด sequence) มีข้อยกเว้นขนาดแผ่นทองบนมือถือ (AGENTS ข้อ 2) — ห้ามแก้ `PAD_WIDTH`/ภาพเกาะ
สำรวจก่อนว่าเกมเรียงอะไร (ขนาด/ลำดับเหตุการณ์/จำนวน) และด่านใช้ชุดของอย่างไร

## งาน
- เพิ่มชุดของใหม่อย่างน้อย 3 ชุด (ชุดละเท่ากับจำนวนช่องเดิม) ตามแบบเกมเดิม — **สิ่งของ/พืช/ธรรมชาติเท่านั้น** เช่น ต้นไม้โตจากเมล็ด (เมล็ด→ต้นอ่อน→ต้นเล็ก→ต้นใหญ่), ดวงจันทร์เสี้ยว→ครึ่ง→ค่อนดวง→เต็มดวง, ถ้วยน้ำจากว่างถึงเต็ม, บล็อกจากเล็กถึงใหญ่ — เลือกที่เข้ากับกติกาเกมจริง
- ภาพของแยกพื้นหลังโปร่งใส สไตล์/ขนาดตามของเดิม ไม่มีตัวหนังสือ ไม่มีใบหน้าบนวัตถุ
- ให้ชุดใหม่ถูกเล่นจริง (หมุนต่อรอบหรือสุ่มฝั่ง client หลัง mount) ชุดเดิมยังเล่นได้ ดาว/ความก้าวหน้าไม่ปะปน คำสั่งเสียงเดิมยังถูกต้องกับทุกชุด (ถ้าคำสั่งเดิมเฉพาะชุดเดิม ให้ทำคำสั่งกลางหรือรายงาน)
- แตะใกล้แผ่น `dropTargetAt` ต้องยังทำงานกับของใหม่
