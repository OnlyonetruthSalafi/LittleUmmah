# LOGO-1 fix 1 — เจ้าของโปรเจกต์เลือกแบบ B + ปรับ 2 จุด
**model `gpt-6-astra` (medium) · timeout 7200 · worktree `D:/Littleummah-logo1` (ทำต่อจากงานเดิม) · พอร์ต 3143**
กติกาเดิมจาก `LOGO-1-brand-redesign.md` · ห้าม commit/reset/unstage

เจ้าของโปรเจกต์ (8 พ.ย. 2026): "เอาแบบ B แต่ขอด้านหลังไม่ใช่มัสยิดเป็นรูปหนังสือแทน และข้อความด้านล่างต้องไม่ใช่ข้อความธรรมดา ต้องสวยคมชัด มีสีสัน"

1. **ตราด้านหลังริบบิ้น: เปลี่ยนจากโดม/อาคารเป็นหนังสือ** — หนังสือเปิด 3D ตั้งเด่นอยู่หลังริบบิ้น (สไตล์เดียวกับเกาะหมวดหน้าแรก ปกฟ้า/เทอร์ควอยซ์ ขอบทอง หน้ากระดาษครีม) ประดับพระจันทร์เสี้ยว ดาว แสงทองได้
   **ไม่มีโดม หออะซาน หรืออาคารใดๆ** · ไม่มีตัวหนังสือ/ตัวอักษรอาหรับในภาพ · ไม่มีคน/สัตว์ · WebP โปร่งใส defringe ขอบ scan alpha · ทำ 2–3 ตัวเลือกใน `output/logo-1/options-fix1/` แล้วเลือกที่เข้ากับริบบิ้นที่สุด
   ขนาด/ความสูงรวมของโลโก้ห้ามสูงกว่าแบบ B เดิม (ดีถ้าเตี้ยลงเล็กน้อย จะได้ไม่ดันเกาะลงมาก)
2. **คำโปรย "อุมมะฮ์ตัวน้อยในวันนี้ คือ ผู้ใหญ่ในวันหน้า"** ห้ามเป็นข้อความธรรมดาบนป้ายขาว — ทำเป็นตัวหนังสือตกแต่งแบบ sticker ที่คมชัดมีสีสัน เข้าชุดกับชื่อและ "Learn, Play, Grow"
   เช่น ฟอนต์ไทยหนา (Noto Sans Thai Looped ตัวหนาสุด ตามข้อ 3) ขอบขาวหนา + เงานูน แบ่งสีตามวลี (เช่น "อุมมะฮ์ตัวน้อยในวันนี้" ฟ้า–น้ำเงิน, "คือ" ทอง, "ผู้ใหญ่ในวันหน้า" เขียว/เทอร์ควอยซ์) หรือบนริบบิ้นเล็กที่สองใต้ริบบิ้นหลัก
   - **ยังเป็นข้อความจริงด้วยโค้ด** (SVG/HTML) ไม่ใช่ภาพ · อ่านง่ายบนมือถือ 390px (ตัวสูงอย่างน้อย ~14px, ห้ามขึ้นบรรทัดแตกกลางวลี) · คมชัดไม่เบลอ (ใช้ stroke/paint-order ไม่ใช้ filter blur)
   - contrast สีตัวอักษรกับขอบขาว ≥ 4.5:1 ทุกสี
3. ตั้งแบบ B ใหม่เป็นค่าเริ่มต้น แล้ว **ลบแบบ A, C และโค้ดสลับ variant ออก** ให้เหลือโลโก้เดียว (รวมไฟล์ภาพที่ไม่ใช้แล้ว) ลบ SVG `BrandMarkIcon` ถ้าไม่มีที่ใช้แล้ว
