## ขั้นที่ 3 — เกาะมือถือของเกมความจำ (MEM-1)
- ภาพที่ Claude เลือกแล้ว:
  - ด่าน 1–2: `D:/Littleummah/output/memory-mobile-island/island-mobile-a.png`
  - ด่าน 3 (จัด 4×4): `island-mobile-tall-b.png`
  - กรอบผิวครีมที่วัดไว้อยู่ใน `measure.json` และ `measure-tall.json` ในโฟลเดอร์เดียวกัน
- ใช้ภาพเหล่านี้เฉพาะจอมือถือแนวตั้ง จอแท็บเล็ต เดสก์ท็อป และแนวนอนใช้ `island.webp` เดิม
- นำภาพเข้า `public/games/memory/` เป็น WebP ผ่าน `scripts/optimize-images.mjs` และใส่ sha256 ใน `source-images.json`
- วาง `.isl-surface` ตามกรอบที่วัดไว้ ห้ามกะด้วยตา ด่าน 3 บนมือถือแนวตั้งจัดเป็น 4×4 (ตรวจว่าเกมรองรับโดยคู่การ์ดยังครบ)
- **ย่อหัวเกมตอนกำลังเล่นบนมือถือแนวตั้ง** ให้ทั้งหน้าไม่ต้องเลื่อนที่ 360×780, 390×844, 430×932
  - ปุ่มที่เด็กกดต้อง ≥64px และข้อความไทยนำต้องยังอยู่
  - ห้ามซ่อนข้อมูลที่จำเป็นต่อการเล่น
- เป้าหมาย: การ์ดทุกด่านบนจอ 360–430 ได้ ≥64px
  - ถ้าได้ครบ ให้แก้ข้อความข้อยกเว้นเกมความจำใน `AGENTS.md` ข้อ 2 ให้ตรงกับผลจริง (เขียนตัวเลขที่วัดได้) แล้วรายงานว่าแก้ตรงไหน
  - ถ้าไม่ได้ ห้ามแก้ AGENTS ให้รายงานตัวเลขแทน
- เพิ่มกรณีทดสอบใน `check-memory-browser.mjs`: วัดขนาดการ์ด ต้องไม่มีการเลื่อนหน้า และภาพเกาะมือถือต้องถูกโหลด
