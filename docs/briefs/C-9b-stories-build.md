## งาน
1. **ภาพ:** ทำปก + ปก deluxe + ภาพทุกหน้า (8 + 10 หน้า) ตาม prompt ในร่างและสไตล์นิทานเดิม
   - **ไม่มีคน ไม่มีสัตว์ ไม่มีศาสดา และไม่มีตัวหนังสือ** ใช้สวน ต้นไม้ ผลไม้ ท้องฟ้า และสิ่งของเล่าเรื่องแทน
   - ไม่มีรอยเท้าหรือเงาที่เป็นรูปคน
   - สวนสองแห่งต้องมีองุ่น ล้อมด้วยต้นอินทผลัม มีพืชระหว่างสวน และมีลำน้ำ ตาม 18:32–33
   - ภาพสวนที่ถูกทำลายให้นุ่มนวล ไม่น่ากลัว ไม่มีไฟ และไม่เติมชนิดภัยที่ตัวบทไม่ได้บอก
     (เล่มเด็กเล็กเลี่ยงฟ้าผ่า · เล่ม 7+ หน้า 7 เป็นคำเตือนเท่านั้น ห้ามวาดฟ้าผ่ากำลังลงจริง)
   - **ห้ามวาดสวนที่ฟื้นแล้ว** หรือสวนใหม่ที่มาทดแทน (68:32 เป็นแค่ความหวัง)
   - ภาพทุกภาพต้อง scan alpha และตรวจว่าไม่มีคนหรือสัตว์ซ่อนอยู่ ถ้าจำเป็นให้ซูมดูทีละส่วน
2. **ใส่เข้าเว็บ:** เพิ่มใน `stories/index.ts` และ `lib/lessons.ts` ให้ขึ้นชั้นหนังสือตามวัย (kids / juniors)
   เพิ่มภาพเข้า JOBS ของ optimizer และใส่ sha256
3. **เสียง:** ใช้ `scripts/make-story-voice.mjs` ตามแบบเล่มเดิม พากย์เฉพาะข้อความไทยและ `meaning` ไทย
   **ห้ามใช้ `--arabic` และห้ามให้หุ่นอ่านอาหรับ** (ข้อ 1.6) ถ้าคำไหนอ่านผิด ให้อัดใหม่ทั้งบรรทัด
4. **ตรวจ:** รัน `check-storybook-browser.mjs --story=<slug>` ทั้งสองเรื่อง + `check-bookshelf-browser.mjs` + `npm run verify`
   ถ่ายภาพทุกหน้าที่ 360×780 และ 1280×720 แล้วทำ montage ภาพทุกหน้าของแต่ละเล่ม
