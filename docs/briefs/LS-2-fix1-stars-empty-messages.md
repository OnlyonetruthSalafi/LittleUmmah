## ต้องมีครบ (ข้อความเป็น text จริงบนจอ ไทยนำ + อังกฤษ และมีเสียงครู)
1. **หน้าดาวหมด** (ตอนกดเริ่มด่านแต่ไม่มีดาว/เครดิต/รอบฟรี) ต้องมีข้อความบนจอ ไม่ใช่เสียงอย่างเดียว:
   - หัวเรื่อง: "ดาวเรียนรู้หมดแล้ว" / "Out of Learning Stars"
   - ข้อความ: "ไปเรียนที่เกาะเรียนรู้เพื่อเก็บดาวก่อน แล้วกลับมาเล่นนะ" / "Go learn on a learning island to collect stars first, then come back to play."
   - เสียง `ls-empty` (มีแล้ว) + ปุ่ม "ไปเรียนเก็บดาว" และ "สำหรับผู้ปกครอง" (≥64px)
2. **เตือนล่วงหน้าเมื่อใช้ดาวดวงสุดท้าย** (หักดาวแล้วยอดเหลือ 0 และวันนี้ใช้รอบฟรีไปแล้ว):
   ป้ายเล็กบนหน้าเล่น (ไม่บังเกม ไม่กระพริบ): "ดาวดวงสุดท้ายแล้ว เล่นจบด่านนี้ ไปเรียนเก็บดาวก่อนนะ" / "This is your last star. After this level, go learn to collect more."
   + เสียงใหม่ `ls-last`: **"ดาวดวงสุดท้ายแล้วนะจ๊ะ เล่นด่านนี้จบแล้ว ไปเรียนเก็บดาวที่เกาะเรียนรู้ก่อนนะ"** (บทอนุมัติแล้ว ห้ามแก้คำ)
3. **หน้าผ่านด่านเมื่อไม่มีดาวเหลือ:** ปุ่ม "ด่านต่อไป"/"เล่นอีกครั้ง" ห้ามพาไปหน้าดาวหมดแบบงงๆ — แสดงข้อความเดียวกับข้อ 1 แทน พร้อมปุ่ม "ไปเรียนเก็บดาว" เป็นปุ่มหลัก (ยังมีปุ่มกลับหน้าเกาะเกม)
4. **หัวเกาะเกมเมื่อยอด 0 และไม่มีเครดิต/รอบฟรี:** แถบข้อความ "ต้องไปเรียนเก็บดาวก่อนนะ" + ปุ่ม "ไปเรียนเก็บดาว" (เด็กรู้ก่อนกดเกม) — ยอดดาวเหลือ 1 ให้บอก "เหลือดาว 1 ดวง"
5. ปุ่ม "ไปเรียนเก็บดาว" ไปปลายทางเดียวกับปุ่ม "ไปเกาะเรียนรู้" ที่เลือกไว้ใน LS-2
6. เมื่อระบบดาวถูกปิดในหน้าตั้งค่า ห้ามแสดงข้อความทั้งหมดนี้
