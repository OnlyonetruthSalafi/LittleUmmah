## งาน
เจ้าของโปรเจกต์จะส่งภาพแต่ละซีนเป็น **start frame** ให้ Google Veo 3.1 (ผ่าน ElevenLabs) สร้างคลิปซีนละ 8 วินาที แล้วต่อกันเป็นการ์ตูน
ภาพเฟรมแรกต้องถูกกฎก่อน Veo จึงจะสร้างได้ตรง — สร้างด้วยเครื่องมือสร้างภาพของ Codex ทีละซีน ตามลำดับ

1. **ภาพตัวละครมด (`ant-sheet.png`)** ก่อน: มดตัวเอกตัวเดียวกับใน `p05.png` (สีน้ำตาล หัวกลมเรียบ หนวดสองเส้น) ท่ายืน/เดิน/ยกขาหน้า มุมหน้า ข้าง หลัง — **หัวเรียบไม่มีตา ปาก คิ้ว แก้ม หรือรอยใดๆ ที่เป็นหน้า**

2. **ภาพซีน S01–S09** ขนาด **1920×1080 (16:9)** PNG ภาพเต็มเฟรม ไม่มีพื้นโปร่ง สไตล์ 3D การ์ตูนเด็กพรีเมียมแบบภาพอ้างอิง แสงอุ่น สีฟ้า เทอร์ควอยซ์ ขาว ทอง

## กฎภาพ — บังคับทุกซีน (AGENTS.md ข้อ 1.1, 1.4, 1.5)
- **ไม่มีคนเลย** ไม่มีมือ ไม่มีเงาคน ไม่มีทหาร **ไม่มีนบีสุลัยมาน ไม่มีญิน** — กองทัพแทนด้วยฝุ่น ธง และเงานกไกลๆ เท่านั้น เหมือนภาพหนังสือเดิม
- มดและนกทุกตัว **ใบหน้าว่าง** ไม่มีตา จมูก ปาก คิ้ว ขนตา แก้มแดง หรือเงาที่ดูเป็นตา/ปาก
- ไม่มีตัวหนังสือ ป้าย ลายน้ำในภาพซีน ไม่มีสัญลักษณ์ดนตรี ไม่มีสัตว์ล่าเหยื่อ ไม่มีเลือด
- ไม่เติมรายละเอียดเนื้อเรื่องที่ตัวบทไม่ได้บอก (ไม่มีวัง ไม่มีชื่อสถานที่ ไม่นับจำนวนกองทัพ ไม่มีมดถูกเหยียบ)
- **ตรวจทุกภาพ:** ซูมหัวมด/นกทุกตัว รวมตัวเล็กไกลๆ (imagegen ชอบเติมตาเล็กๆ) ถ้าเจอ สร้างใหม่หรือแก้ แล้วเก็บภาพซูมหัวมดใน `zoom/`

## prompt สำหรับ Veo
เขียน `scenes.json`: รายการ `{ id, file, narration, duration_secs: 8, prompt, negative_prompt }` ภาษาอังกฤษ
- prompt บรรยายการเคลื่อนไหวตามตารางข้างบน ช้า นุ่ม เหมาะเด็กเล็ก ไม่มีแสงกระพริบ ไม่มีกล้องสั่น
- ทุก prompt มีประโยค: "All ants and birds have completely blank smooth heads with no eyes, no mouth, no face. No people, no humans, no soldiers. No text. No music, no singing, no musical instruments."
- negative_prompt: "eyes, face, mouth, eyebrows, smile, people, humans, soldiers, hands, king, text, letters, watermark, music, singing, musical instruments"
- ห้ามเรียก API ของ ElevenLabs หรือ Veo เอง (Claude/เจ้าของโปรเจกต์จะส่งเอง)
