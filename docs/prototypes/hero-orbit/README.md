# ต้นแบบ Hero "เกาะโคจร" (ยังไม่ใช้ในเว็บ)

ทำ 8 พ.ย. 2026 ตามที่เจ้าของโปรเจกต์ขอดูตัวอย่าง — **เก็บไว้ใช้หลังเจ้าของโปรเจกต์ประชุมกับผู้สนับสนุนทุน** ยังไม่ได้อนุมัติให้ใส่หน้าแรก

- เปิดดู: เปิด `index.html` จากโฟลเดอร์นี้ในเบราว์เซอร์ (ภาพดึงจาก `public/islands/`) หรือเสิร์ฟจาก root ของ repo
- แนวคิด: เกาะทั้ง 10 โคจรบนวงรี ภาพหันหน้าเข้ากล้องเสมอ (ไม่ใช้ rotateY แบบตู้หนังสือใน `D:\salafiwebsite` เพราะภาพเกาะมุม 3/4 จะบี้)
  เกาะหลังเล็ก/จาง เกาะหน้าแสดงชื่อ + ป้ายโซน · ปัด/ลูกศร 64px/คีย์บอร์ด แล้ว snap · Tab ถึงเกาะไหนหมุนเกาะนั้นมาหน้า · ล็อก = ข้อความ "ยังไม่เปิด"
- **กฎที่ต้องตัดสินก่อนใช้จริง:** หมุนเองต่อเนื่องขัด AGENTS.md ข้อ 2.1 (ห้ามลอย/วนตลอดเวลา) — ต้นแบบหมุนเฉพาะเมื่อผู้ใช้สั่ง ช่องติ๊ก "หมุนเอง" มีไว้เปรียบเทียบเท่านั้น
  ต้องมี fallback ตอน prefers-reduced-motion (ใช้โค้ง ∩/U แบบหน้าแรกปัจจุบัน)
- ข้อสังเกต: มือถือเห็นชัด 3 เกาะ เกาะหลังซ้อนแน่น — ถ้าทำจริงพิจารณาลดจำนวนเกาะบนมือถือหรือทำวงแบนลง
- ถ้าจะทำจริง: brief ให้ Codex (astra) 1–2 รอบ ย้ายเป็น component React + ใช้ข้อมูลจาก `HOME_ISLANDS` ใน `src/lib/categories.ts`
