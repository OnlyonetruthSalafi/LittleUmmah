0. ภาพรวมระบบในหนึ่งย่อหน้า
==================================================================
เป็น 2.5D cut-out บน <canvas> ไม่ใช่ 3D และไม่ใช่ physics engine
ฉากหลังเป็นภาพเดียว 1920x1080 (park.jpg) = พิกัดโลก
ตัวละครหุ่นยนต์แต่ละตัวมี "ชุดมุม" (kit) หลายชุด: front / q (เฉียง 3/4) / side / back
แต่ละชุดคือ PNG ชิ้นส่วน + rig.json (pivot, parent, z, ground, anchorX, scaleToFront)
ทุกอย่างกำกับด้วย keyframe ตามเวลาของเสียงพากย์ แล้ว renderAt(t) วาดเฟรมแบบกำหนดแน่นอน
Playwright เปิด stage.html ทีละเฟรม 24fps → ffmpeg → render.mp4 (ภาพเงียบ) → mix.mjs ผสมเสียง → master.mp4

1. มิติ (2.5D) — ทำให้ภาพแบนดูมีความลึก
==================================================================
1.1 ความลึกด้วยการเรียงวาดตามแกน y
  render() รวมตัวละคร + พร็อพ + extras เป็นรายการ แล้ว sort ตาม d = y + depth
  ของที่ y มากกว่า (ใกล้กล้อง) วาดทีหลัง → บังของที่อยู่ไกล
  พร็อพบนโต๊ะใช้ depth คงที่ (950–956) ทศนิยมคุมลำดับละเอียด เช่น blue 954.1 / gold 954.2
  ตัวละครปรับ 'depth' เพิ่มได้ (ฮาดี depth 35 ให้ยืนหน้าโต๊ะ)
1.2 ระนาบพื้นผิวหลายระดับ
  โต๊ะมีหน้าโต๊ะ TOP=725 รถทองวาง TOP+20 = "เลนใกล้" รถฟ้า TOP = "เลนไกล"
  → รถสองคันไม่ทับกันเพราะอยู่คนละเลนความลึก (check-motion ตรวจ minTruckGap ≥ 0)
1.3 เงาบอกความสูง
  - เงาสัมผัสใต้ล้อ/สายพาน (contactShadow): วัดขอบล่างทึบจริงของภาพล้อทุกเฟรม (alpha>180)
    วาดวงรีสองชั้น (มืดแคบ + เงาฟุ้ง) ใต้ "แต่ละ" ล้อ — แทนเงาวงเดียวกลางตัว (เจ้าของสั่งแก้)
  - หุ่นลอย (ซาฟี hover alt 150): เงาจางและกว้างขึ้นตามความสูง k = 1 - alt/420
  - พร็อพที่ถูกยก: เงาอยู่บนพื้นผิวเดิม จางลงตาม lift = surface - y
  - เงาโต๊ะ + เงาขาโต๊ะ วาดเป็น extra ก่อนทุกอย่าง
1.4 กล้องซูม/แพน
  cut(t,x,y,z) = ตัดภาพทันที · camTo(a,b,x,y,z) = เคลื่อนกล้องนุ่ม
  ซูม 1.12–2.05 ภายในภาพฉากเดียว (clamp ไม่ให้เห็นขอบ) ใช้ระยะกล้องเน้น "เหตุและผล"
1.5 ล้อหมุนตามระยะทางจริง
  ล้อของรถสะสมระยะเฉพาะตอนแตะพื้นผิว (|y - surface| < 0.2) — ยกขึ้นแล้วล้อค้าง
  ล้อหุ่นหมุนตาม x / (radius*scale) · สายพานใช้ pattern เลื่อนตาม x แล้ว mask

2. การหมุนตัว (turn)
==================================================================
  RING = ['front','q','side','back'] ตำแหน่งบนวง: front 0, q ±1, side ±2, back ±3 (ลบ = หันซ้าย/flip)
  turn(id, t, view, flip, step=.13):
   - หาเส้นทางสั้นที่สุดรอบวง แล้วไล่ "ผ่านทุกมุมระหว่างทาง" (หน้า→เฉียง→ข้าง)
   - แต่ละขั้น: บีบความกว้าง sq→0.96 (ช่วง 45% ของ step, ease in) → สลับชุดภาพ view/flip ตรงจุดบีบ
     → คืน sq=1 (ease out) · ขั้นละ 0.13–0.18 วิ
   - CAST[id].skip: มุมที่ข้ามได้ระหว่างทาง (เช่นเพื่อนข้าม front) แต่ถ้าเป็นมุมปลายทางยังใช้
   - คืนค่าเวลาที่หมุนเสร็จ → ใช้ต่อคิวถัดไปได้
  บทเรียนจาก truth → share: ลดการบีบจาก 0.8 เหลือ 0.96 ภาพไม่ดูเป็นยาง
  rig ช่วยให้สลับชุดไม่กระโดด: ground (เส้นพื้นของ canvas 1024), anchorX (แกนหมุน), scaleToFront (ขนาดเท่ามุมหน้า)
  กฎการใช้:
   - หันเพราะมีเหตุ: มองของ / หันหาเพื่อน / หันหาผู้ชมตอนถาม-ลา
   - "จังหวะคิด" = head มองของ → turn หาเพื่อน → head กลับ 0 (film.js ส่วน 3 ท้าย)
   - ช่วงสอนและลา ครูนูรีหัน 'front' หาผู้ชม; ซาฟีหัน front โบกมือตอนจบ

3. การเคลื่อนไหว
==================================================================
3.1 ระบบ keyframe
  key(id, prop, t, v, ease) · to(id, prop, t0, t1, v) = ค้างค่าเดิมถึง t0 แล้วไปค่าใหม่ที่ t1
  set() = เปลี่ยนแบบ step · ease: io (smootherstep), in, out, back, bounce, lin
  ข้อต่อ: prop 'j:<view>:<part>' เป็นมุมองศาเพิ่มจาก restPose (แยกตามชุดมุม)
  เวลาอ้างเสียงเสมอ: T('b02') = เริ่มบรรทัด, TE('b02') = จบบรรทัด, S('talk') = เริ่มฉาก
  → แก้บท/อัดเสียงใหม่ แอนิเมชันเลื่อนตามเองอัตโนมัติ
3.2 คำสั่งการแสดงที่ใช้ซ้ำ (cast.js / film.js)
  drive(id,t0,t1,x,y,{end,endFlip}) : หันข้างไปทางที่จะไป → เอนไปหน้า 3.5° ตอนออกตัว
     → เอน 2° ระหว่างทาง → เบรกเอนกลับ -3° → คืน 0 → หันกลับเป็นมุม end · ใส่ SFX tread/brake อัตโนมัติ
  gesture(id,view,t0,t1,angles) : ยกแขนขึ้น 0.4 วิ ค้าง แล้วคืน 0.45 วิ ก่อนจบบรรทัด
     ท่ามาตรฐาน OPEN (กางสองแขน), FWD (ยื่นแขนขวา), BOTH (สองแขนสูง)
  head(id,a,b,deg) : เอียง/ก้มหัว — ใช้แสดงความลังเล การฟัง การมองของ
  ตา/ปาก: set eyes 'open'/'wide'/'happy', mouth 'flat'/'smile' · กระพริบตาเองตาม blinkEvery
  ปากตามเสียง: envelope ระดับเสียง 24 ค่า/วิ → small/open/wide (ไม่ใช่ lip-sync รายหน่วยเสียง)
  หัวพยักเล็กตามระดับเสียงขณะพูด · หุ่นลอยมี bob ไซน์
3.3 จับ/ยก/ส่งของ (หัวใจของเรื่องนี้)
  grip(id, prop, จุดจับบนภาพพร็อพ, a, b, {tin,tout,elbow}):
   - IK สองข้อ (solve) ล็อกมือขวาเข้าจุดจับในพิกัดโลก ค่อย ๆ เข้า tin / ออก tout
   - follow: ตัวละคร "ขยับลำตัวเข้าระยะเอื้อมก่อน" แล้วมือจึงปิด (ไม่ยืดแขนจากที่ไกล)
   - ระหว่างจับ พร็อพยังมีพิกัดโลกของตัวเอง มือแค่ตาม → ไม่มีการเปลี่ยน parent ตอนส่งต่อ
  การส่งรถ (ส่วน 4): ผู้ให้ยก → พาเข้าระยะผู้รับ → ผู้รับจับ (take) → "จับร่วมกัน" ค้างช่วงหนึ่ง
     → ผู้ให้ปล่อย (release) → ผู้รับวางลง (land) · ตรวจว่าพร็อพไม่กระโดด ≤1px@720p ทุกจุด
  ใส่ของลงรถ: ตอนวางเปลี่ยน attach เป็นลูกของรถ โดยคำนวณพิกัดให้ตรงพิกัดโลก (คลาด <0.007px)
     และชดเชย scale (.14/TRUCK_SCALE) → บล็อกไปกับรถและเอียงตามแรงชน
  การบัง: frontGrip วาดเฉพาะ 'hand-r' ซ้ำทับพร็อพ (ก้ามอยู่หน้าของ) — ไม่วาดหุ่นทั้งตัวซ้ำ
3.4 การชน (ส่วน 5)
  hit เป็นเวลาเดียวที่ขับทุกอย่าง: รถเด้งถอย 1097→1093→1094, บล็อกขวางเอียง 7°→-2°→0 และขยับ,
  สินค้าบนรถเอียง -5°→2°→0 (คนละจังหวะกับรถ), ตาตัวละคร 'wide', หัวผงะ, SFX bump
  แล้วตามด้วย "การแก้ไข": ถอยรถ → ตัวละครเข้าระยะ → grip บล็อก → เลื่อนออกนอกเลน → ขับต่อ
  ลำดับ: เตรียม → สัมผัส → รับแรง → คืนนิ่ง → รับรู้ผล → แก้ไข
3.5 หลักกำกับที่ทำให้ดูมีชีวิต
  - ตัวที่ฟังนิ่ง ขยับเฉพาะเมื่อมีความหมาย; คนพูดใช้ gesture ทุกบรรทัด
  - ของที่ไม่ได้ใช้เป็น "ผลเงียบ": รถฟ้าจอดรอ + ฮาดีหันกลับไปมอง (ไม่ต้องพูด)
  - ทุกการเคลื่อนของ ต้องมีมือสัมผัสอยู่ (รถทองขยับเฉพาะตอนฮาดีจับ)
  - การคืนของแสดงด้วยภาพ ไม่ใช่แค่พูด (ส่วน 6 รถกลับมาจอดข้างกันครบ)
  - จัดกล้องให้เห็นตัวเอกเต็มตัวและจุดสัมผัส ไม่ให้ตัวละครบังจุดเกิดเหตุ

4. บท (story.mjs)
==================================================================
4.1 โครง 7 ฉาก (~3.4 นาที, 35 บรรทัด)
  city   ปูเรื่อง: ของเล่น/ใครเป็นเจ้าของ/กิจกรรมร่วม
  keep   ปัญหา: ขอยืม → ปฏิเสธ (มีเหตุผล "กลัวเป็นรอย") → เพื่อนเคารพ ไม่แย่ง → ผลเงียบ
  talk   ครูรับฟังก่อน ยอมรับความรู้สึก → ชวนหาวิธี → ให้ตัวเอก "เลือกเอง"
  share  ตัวเอกตัดสินใจ + ลงมือ (ส่งของอย่างปลอดภัย)
  play   เล่นด้วยกัน + อุปสรรคเล็ก ๆ → ช่วยกันแก้
  return คืนของ ขอบคุณกัน ครูสรุปสิ่งที่เห็น
  ask    ครูถามเด็ก เว้นให้ตอบ → ชวนพูดตาม (turns.json หยุดรอ) → บอกลา + ทุกคนโบกมือ
4.2 รูปแบบข้อมูล
  lines = { key: [ตัวละคร, ข้อความ] } หนึ่งบรรทัด = หนึ่งไฟล์เสียง voice/<key>.mp3
  scenes = [{id, lead, tail, items:[[key, ช่องว่างก่อนพูด(วิ)]]}]
  ช่องว่างคือ "เวลาให้ภาพเล่า" — เช่น b04 เว้น 2 วิ ให้ฮาดีเข็นรถ, e06 เว้น 4.2 วิ ให้เคลียร์บล็อก, g02 เว้น 4.5 วิ ให้เด็กตอบ
  prepare.mjs วัดความยาวเสียงจริง → timing.json, envelope ปาก, .vtt, turns.json (turnAfter)
4.3 ภาษา/น้ำเสียง (เจ้าของสั่ง)
  เพื่อนใช้ครับ/ค่ะ แต่ไม่ถี่ · ครูนูรีใช้ "นะจ๊ะ/จ๊ะ" · แทนตัวว่า "เรา" ระหว่างเพื่อน
  เรื่องสมมุติของหุ่นยนต์ประกอบบทเรียนเดิม ไม่เพิ่มตัวบทศาสนา/ผลบุญเฉพาะ (ถ้าจะเพิ่ม Claude ต้องตรวจ §1.6)
  บทพูดบรรยายสิ่งที่เห็น ("กันชนแตะบล็อกแล้ว หยุดก่อน") เด็กเล็กโยงคำกับภาพได้
