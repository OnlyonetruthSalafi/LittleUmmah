ข้อสรุปหลัก
ความสมจริงเพิ่มขึ้นจากการกำกับความสัมพันธ์ระหว่างตัวละคร สิ่งของ และเวลา:
ตัวละครมีเจตนา → ลงมือ → ของตอบสนอง → ตัวละครรับรู้ผล → เปลี่ยนใจหรือแก้ไข
ภาพหลายมุม ข้อต่อ จุดจับ และกล้อง ทำให้ลำดับนี้มองเห็นได้ชัด
จึงควรรักษาระบบ 2.5D cut-out หลายมุมนี้เป็นฐาน และพัฒนาการแสดงกับการสัมผัสต่อ
ไฟล์นี้ไม่ได้ใช้โมเดล 3D หรือระบบจำลอง rigid-body; ฉากชนใช้ keyframe ที่กำกับไว้

1. การหันตัวมีความหมายต่อเรื่อง
หลักฐาน: ช่วง 00:47–01:12 และภาพละเอียด 01:02.67–01:03.29 / 01:04.75–01:05.38
ฮาดีมองรอบตัว หันหลัง และหันกลับมาตอนนึกถึงคำสอน การหันทำให้เด็กอ่านความลังเลได้
โดยไม่ต้องให้หน้าจอเป็นผู้สื่ออารมณ์เพียงอย่างเดียว
กลไก: cast.js turn() ไล่ชุด front / q / side / back ตามชุดที่มีและทิศ flip
engine.js ใช้ anchorX, ground และ scaleToFront ช่วยจัดตำแหน่งและสเกลระหว่างชุด
สิ่งที่ต้องใช้ต่อ:
- เลือกมุมจากสิ่งที่ตัวละครกำลังมองและกำลังจะทำ
- สร้างเฉพาะมุมที่บทต้องใช้ และตรวจสัดส่วน/วัสดุ/ฐานของทุกมุมก่อนทำเรื่อง
- ใช้ข้อต่อเคลื่อนต่อเนื่องภายในมุมเดียว แยกจากการเปลี่ยนชุดภาพเมื่อเปลี่ยนมุม
ข้อจำกัด: turn() ยังสลับชุดเป็นขั้นและบีบความกว้างถึง 0.8 ชั่วคราว
การหันจึงยังมีการเปลี่ยน silhouette ชัดเมื่อไล่ทีละเฟรม ไม่ใช่การหมุน 3D ต่อเนื่อง
ข้อปรับจากบทเรียน 15 พ.ย.: ภาพหลายมุมที่คุมดีไซน์แล้วช่วยเล่าเรื่องได้จริง
แต่ไม่ควรถือว่าการบีบภาพอย่างเดียวสร้างมุมข้างหรือมุมหลังได้
เรื่องถัดไปให้ประเมินการหันที่ความเร็วจริง ลดการบีบถ้าดูเป็นยาง และเพิ่มมุมเฉพาะเมื่อจำเป็น

2. ฉากชนสำเร็จเพราะมีผลตามมาเป็นทอด ๆ
หลักฐาน: ภาพ 00:41.25–00:43.63; film.js ส่วน bump
- 41.484: เวลา hit ใน timeline ฮาดีถึงโต๊ะ โต๊ะสะเทือน และฮาดีเริ่มผงะ
- โต๊ะขยับจากจุดตั้งต้น +16 → -6 → +3 → 0 พิกเซลโลก พร้อมเอียงแล้วคืน
- ฮาดีเอนจาก 9° ไป -7° ถอยจาก x=792 ไป 742 และกระเด้งเล็กน้อย
- 41.984: กังหันเริ่มล้มหลังโยก; 42.604: ล้มถึงหน้าโต๊ะและเปลี่ยนเป็นใบหัก
- ชิ้นใบแยกตก หมุน กระดอน แล้วหยุดบนพื้น; ตัวเสากังหันล้มค้างอยู่บนโต๊ะ
สิ่งที่ต้องใช้ต่อ:
- ระบุจุดสัมผัสและเวลา hit เป็นเหตุการณ์ร่วมของตัวละคร ของ กล้อง และคิว SFX
- แยกเตรียมตัว / สัมผัส / รับแรง / ผลตามมา / กลับสู่นิ่ง
- ให้ชิ้นที่หนักและเบาตอบสนองต่างจังหวะ ไม่สั่นทุกอย่างพร้อมกัน
- ใช้ keyframe ที่อ่านเหตุและผลได้ชัดก่อนเพิ่มระบบจำลองฟิสิกส์
ข้อควรตรวจต่อ: นี่เป็นการชนที่กำกับด้วยภาพและค่าเวลา ไม่ใช่ผลทดสอบ collision อัตโนมัติ
ต้องตรวจจุดสัมผัสจริงและการทะลุของทุก action ใหม่ ไม่คัดค่าพิกัดนี้ไปใช้กับโต๊ะอื่นทันที

3. สิ่งของมีสถานะต่อเนื่อง และการซ่อมเป็นการแสดงจริง
หลักฐาน: 00:55–00:59 ฮาดีตั้งกังหันกลับ; 03:06.5–03:12.8 เพื่อนช่วยกันซ่อม
ฮาดีจับเสา ซาบิรมีใบสำรอง ซาฟีรับและนำไปติด แล้วใบสีทองอยู่ในกังหันที่กลับมาหมุน
เศษใบเก่ายังอยู่บนพื้น จึงมีหลักฐานทางภาพเชื่อมเหตุการณ์ต้นเรื่องกับตอนท้าย
กลไก: engine.js solve() จัดข้อต่อแขนด้วย IK; propMat() ผูกพร็อพกับมือหรือพร็อพแม่
film.js เปลี่ยนผู้ถือใบใหม่จากซาบิรเป็นซาฟีที่ 188.712 และติดใบที่ 191.012 ตาม timeline
สิ่งที่ต้องใช้ต่อ:
- ทำตารางสถานะวัตถุ: อยู่ที่ใด ใครถือ จับตรงไหน สมบูรณ์/เสีย/ซ่อม และถูกใครบัง
- ยึดจุดจับเดียวร่วมกันระหว่างมือกับสิ่งของ
- ตอนส่งต่อหรือปล่อย ต้องรักษาตำแหน่งและมุมในโลกก่อนเปลี่ยน parent
- ตรวจทั้งตำแหน่งและภาพนิ้ว/ก้ามบังหน้า–หลัง อย่าสรุปว่ามือจับดีเพียงเพราะ IK มีอยู่
- ทำ asset สภาพก่อนเกิดเหตุ/หลังเกิดเหตุ/ซ่อมเสร็จให้ใช้ขนาดและจุดอ้างอิงเดียวกัน
การใช้ใบใหม่สีทองช่วยสื่อว่า “ซ่อมแล้ว” แม้เด็กยังอ่านหนังสือไม่คล่อง

4. อารมณ์มาจากการกระทำและจังหวะเว้น
หลักฐาน: 01:27–01:30 ฮาดีก้มและหันกลับก่อนสารภาพ; 01:39–01:41 ก้มขอโทษ
ช่วงก่อน d03 เว้น 3.6 วินาทีจากจบบรรทัดก่อนตาม story.mjs
จังหวะนี้มีการเปลี่ยนทิศและท่าทาง จึงให้ภาพทำหน้าที่เล่า “กำลังตัดสินใจ”
สิ่งที่ต้องใช้ต่อ:
- เขียนเจตนาของช็อตก่อนเขียนท่า เช่น อยากดู → ตกใจ → อยากปิดบัง → ยอมรับ → ช่วยซ่อม
- จัดทิศหัว ลำตัว มือ และทิศมองให้สนับสนุนเจตนาเดียวกัน
- ตัวที่ฟังควรนิ่งพอให้เห็นผู้พูด แล้วตอบสนองเฉพาะช่วงที่มีความหมาย
- มีจังหวะค้างให้เด็กอ่านเหตุการณ์ได้ ไม่เพิ่มการขยับโดยไม่มีเหตุ
- ปากฉบับนี้ขยับตามระดับเสียง ไม่ใช่ lip sync รายหน่วยเสียง

5. กราฟิกดูมีมิติจากงานภาพและการจัดฉากที่เข้ากัน
สิ่งที่เห็น: ขอบโลหะมีไฮไลต์ ข้อต่อแยกชัด หน้าจอและโดมมีผิวต่างจากตัวหุ่น
ฉากมีพื้นกว้างและเส้น perspective; ตัวละคร พร็อพ และฉากใช้สีฟ้า/เขียวอมฟ้า/ทองร่วมกัน
ตัวละครมีเงาที่ฐาน การยกตัวของซาฟีสัมพันธ์กับระดับเงาใน renderer
กล้องเปลี่ยนจากกลุ่มตัวละครไปเน้นเหตุชน ความลังเล และนูรีช่วงสอน
สิ่งที่ต้องใช้ต่อ:
- รักษาดีไซน์ต้นฉบับ ใช้แสงและวัสดุสอดคล้องระหว่างมุม
- ตรวจเส้นพื้น ขนาดตัวละคร และระดับหน้าโต๊ะร่วมกันตั้งแต่ blocking
- วางพื้นที่สำหรับมือและพร็อพสำคัญก่อนเลือกการซูม
- ใช้ระยะกล้องเพื่อช่วยอ่านการกระทำ ให้เด็กเห็นทั้งสาเหตุและผล
ข้อจำกัด: ฉากเป็นภาพเดียวที่ซูม/แพน ไม่มี parallax 3D หรือแสงคำนวณใหม่ตามท่า
ความสมจริงในที่นี้คือรูปทรงอ่านง่าย วัสดุมีมิติ และเหตุการณ์น่าเชื่อ

6. จุดที่ควรพัฒนาจากต้นแบบนี้
A. ความต่อเนื่องระหว่างมุม: มีการสลับ silhouette ในช่วงหัน
   ทดลองคลิปสั้นโดยรักษาขนาดหัว/ลำตัว จุดพื้นและแกนหัน แล้วดูทั้ง 1× และ 0.25×
B. การจัดช็อตซ่อม: ราว 03:10–03:12 ซาฟี มือ และดุมกังหันซ้อนกัน
   และช่วงปลายลำดับที่ตรวจศีรษะ/โดมซาฟีถูกขอบบนตัด
   เรื่องต่อไปจัดตำแหน่งตัวช่วยหรือขยายกรอบให้เห็นมือ–ใบ–ดุม ก่อนซูมเข้า
C. เงาพร็อพ: เงาสัมผัสใต้โต๊ะและเศษใบอ่านไม่ชัดเท่าเงาตัวละครในภาพที่ตรวจ
   เพิ่มเงาสัมผัสให้วัตถุที่เด็กต้องเข้าใจว่าวางอยู่บนพื้น พร้อมตรวจทิศแสงร่วมกับฉาก
D. ความชัดบนมือถือ: จุดส่งใบเป็นส่วนเล็กเมื่อดูภาพรวม
   ทดลองย่อเป็นขนาดเครื่องเล่นจริง ให้คนดูบอกได้ว่าใครถือและติดใบตรงไหนโดยไม่อ่านบท
E. การใช้ซ้ำ: render.mjs, prepare.mjs และ source ต่าง ๆ มี path เฉพาะ car-truth/เรื่องเก่า
   ต้องแยกค่าของเรื่องและทำรายการ dependency ก่อนยกเป็นแม่แบบ ไม่คัดลอกทั้งชุดแล้วหวังว่ารันได้ทันที
ข้อเสนอเหล่านี้เป็นงานยกระดับเรื่องถัดไป ไม่ใช่การตัดสินว่าต้องรื้อคลิปที่เจ้าของชอบ
