**2. จุดแข็งที่ควรรักษา**

- **ภาษาไทยเป็นฐานจริง** ทั้งเสียงนำทาง ฟอนต์ไทยมีหัว และบริบทครอบครัว ไม่ใช่เพียงแปลเมนูจากแอปต่างประเทศ
- **จุดยืนเนื้อหาชัดและอธิบายหลักฐานได้** ทำให้ผู้ปกครองประเมินความเหมาะสมได้ โดยรักษาข้อตัดสินเรื่องภาพของเจ้าของโครงการไว้
- **นูรีและโลกเกาะมีเอกลักษณ์ร่วมกัน** เชื่อมเกม นิทาน และบทเรียนให้เป็นผลิตภัณฑ์เดียว ควรใช้ตัวเดิมต่อไป
- **เรียนรู้ได้โดยไม่สมัครสมาชิก** มีเสียงช่วยเด็กอ่านไม่ออก และกิจกรรมศิลปะพาออกจากหน้าจอ
- **ฐานเทคนิคเหมาะกับการต่อยอด** เกมแยกโหลดด้วย dynamic import; การ์ตูนมารยาทและสำรวจโลกใช้ส่วนประกอบร่วมกัน ไม่จำเป็นต้องสร้างระบบใหม่ทุกบท
- จุดขายที่ควรสื่อคือ **“ไทยนำ เรียนรู้กับครอบครัว เนื้อหาตรวจสอบได้ และเล่นอย่างไม่กดดัน”** ทั้งนี้ยังไม่ได้สำรวจคู่แข่งเพื่อยืนยันความแตกต่างทั้งตลาด

**3. ทิศทางสู่ Muslim kids hub**

Little Ummah ควรเป็นพื้นที่ฟรีที่เด็กเข้ามาฟัง เรียน เล่น และนำสิ่งเล็ก ๆ ไปใช้ในชีวิตจริง โดยนูรีช่วยนำทางตามช่วงวัย เด็กเล็กเรียนกับผู้ปกครองผ่านภาพและเสียง เด็กโตสำรวจและคิดต่อได้เอง ทุกเนื้อหาศาสนามีที่มาตรวจสอบได้ ประสบการณ์มีจุดจบที่สบายใจ และความสำเร็จวัดจากสิ่งที่เด็กเข้าใจหรือทำได้ มากกว่าเวลาที่อยู่บนเว็บ

- **เสาหลัก:** อัลกุรอานและศรัทธาพื้นฐาน / ดุอาอ์และอิบาดะฮ์ / ภาษาอาหรับ / อะดับ / เรื่องเล่า / สำรวจโลกและศิลปะ / เกมฝึกทักษะ / เครื่องมือผู้ปกครอง
- ไม่จำเป็นต้องเปลี่ยนทั้งหมดเป็น 8 เกาะทันที ใช้หมวดเนื้อหาและทางลัดก่อน เพื่อรักษาความคุ้นเคย
- **แกนกลับมาประจำวัน:** “วันนี้กับนูรี” เลือกกิจกรรมสั้นหนึ่งชุด: ฟังหนึ่งเรื่อง → ลองหนึ่งอย่าง → ไปทำกับครอบครัว เช่น กล่าวสลามหรือช่วยเก็บของ
- ให้เลือกเอง ข้ามได้ ย้อนเรียนได้ และมีปุ่ม “วันนี้พอแล้ว”; ไม่มี streak เสียหาย รางวัลสุ่ม loot box ตารางคะแนน หรือการบังคับทำทุกบท
- ตัวชี้วัดหลัก: เด็กเริ่มเองได้ เข้าใจคำสั่ง ทำกิจกรรมจบ และผู้ปกครองเห็นการนำไปใช้ ผ่านการทดลองกับครอบครัวโดยสมัครใจ

**6. ผลของการมีผู้สนับสนุนให้ใช้ฟรี**

- เปลี่ยนนโยบายเป็น **ฟรีสำหรับผู้ใช้ ไม่มีโฆษณา ไม่มีการขายข้อมูล ไม่มีการติดตามพฤติกรรมเด็กรายบุคคล**; ความคืบหน้าในเครื่องยังมีประโยชน์ แต่ต้องอธิบายและล้างได้
- ให้เครดิตผู้สนับสนุนใน `/parents` หรือหน้าความโปร่งใส ใช้ชื่อและข้อความขอบคุณที่เป็นกลาง ไม่มีสินค้า คูปอง ลิงก์ชวนซื้อ หรือรางวัลติดแบรนด์ในพื้นที่เด็ก
- ทำข้อตกลงว่าเจ้าของโครงการ/ผู้ตรวจเนื้อหายังคุมหลักสูตร ผู้สนับสนุนไม่ได้สิทธิ์ข้อมูลเด็กหรืออำนาจแทรกโฆษณา
- เปิดเผยหมวดค่าใช้จ่าย ระยะทุน และผลงานที่ส่งมอบเป็นรอบ ๆ รายงานความสำเร็จด้วยเนื้อหาที่ตรวจแล้วและผลทดสอบกับครอบครัว ไม่ใช้ยอดเวลาหน้าจอเป็นเป้าหมาย
- คุม hosting ด้วย WebP, cache และชุด deploy สะอาด; ผลิต TTS ล่วงหน้าเป็นไฟล์หลังอนุมัติบท ไม่สร้างใหม่ทุกครั้งที่เด็กกดฟัง
- เตรียมเงินสำรองและโหมดบำรุงรักษา: หากทุนหยุด ให้คงคลังเดิม ลดการผลิตใหม่ และมีผู้รับผิดชอบโดเมน/สำรองข้อมูล ไม่เปลี่ยนเป็นโฆษณาต่อเด็กโดยอัตโนมัติ
- **ยังควรเลี่ยง NC/ND:** ฟรีไม่ได้ตัดสินว่าเป็น noncommercial เสมอ และ ND จำกัดการเผยแพร่งานดัดแปลง การคงกติกาเดิมลดภาระตีความและรองรับการแปล/ปรับสื่อ; ภาพถ่ายยัง CC0/สาธารณสมบัติตามเดิม ([Creative Commons FAQ](https://creativecommons.org/faq/))

**7. แผน 30/60/90 วัน**

- **30 วัน:** ปิดช่องว่าง release/privacy/สิทธิ์ไฟล์ แก้ความเสี่ยงโหลดค้างและดาวทันที ลดชั้น “เร็ว ๆ นี้” วัดมือถือจริง และทดลองกับครอบครัวสองช่วงวัยกลุ่มเล็ก
- **60 วัน:** เปิด “วันนี้กับนูรี” รุ่นเล็ก ดุอาอ์ชุดแรก คู่มือผู้ปกครอง และอักษรอาหรับชุดถัดไป พร้อมกระบวนการตรวจเนื้อหาที่ใช้ซ้ำได้
- **90 วัน:** ใช้ผลทดลองเลือกขยายอาหรับหรืออัลกุรอานชุดเริ่มต้น เติมนิทาน 1–2 เล่ม และประเมินต้นทุน/ความต่อเนื่องของทุนก่อนประกาศ roadmap รอบใหม่

**8. คำถามที่เจ้าของโครงการต้องตัดสิน**

1. ใน 90 วันแรก กลุ่มหลักคือเด็ก 3–6 เรียนกับพ่อแม่ หรือเด็ก 7+ เรียนเอง?
2. เห็นด้วยหรือไม่ให้ “ดุอาอ์–อะดับในชีวิตจริง” เป็นแกนประจำวัน โดยอัลกุรอานเป็นเสาหลักที่พัฒนาคู่กัน?
3. ใครเป็นผู้ตรวจศาสนาและเสียงอาหรับขั้นสุดท้าย และตรวจได้กี่บทต่อเดือน?
4. ผู้สนับสนุนรับรองงบ/ระยะเวลาเท่าไร และยอมรับเงื่อนไขไม่มีโฆษณาหรือสิทธิ์ข้อมูลเด็กหรือไม่?
5. จะยืนยันนโยบายไม่มีบัญชีเด็กและไม่มี analytics รายบุคคล พร้อมเลื่อนแผนบัญชีใน GAME_SYSTEM_PLAN หรือไม่?
6. ก่อนเปิดสาธารณะ ยอมซ่อนรายการที่ยังไม่พร้อมและลดเอฟเฟกต์บางส่วน เพื่อให้หน้าเบาและเด็กเข้าถึงเนื้อหาได้ชัดขึ้นหรือไม่?
