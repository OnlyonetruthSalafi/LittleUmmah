### 1.2 ข้อวิจารณ์

1. **ไม่มีเส้นทางการเรียน (scope & sequence)** — บทเรียนทุกบทมีน้ำหนักเท่ากัน เรียงตามที่ใส่ในไฟล์ เด็กและผู้ปกครองไม่รู้ว่า "สัปดาห์นี้ควรทำอะไร" และ "ทำไปแล้วได้อะไร"
   Hub ระดับโลก (ดูคู่แข่งอย่างเว็บเรียนศาสนาเด็กในตลาดอังกฤษ/มาเลเซีย) ต่างกันที่ **มีแผนรายสัปดาห์ + เป้าต่อช่วงวัย + ตัววัดง่ายๆ** ไม่ใช่จำนวนเกาะ
   - สิ่งที่มีอยู่แล้วและต่อยอดได้: ดาว 3 ดวง = ฝึกกี่วัน (`moral/progress.ts`), ภารกิจวันนี้ 2 บท, ดาวเรียนรู้ 1 ดวง/บท/วัน (`learning-stars/model.ts`)
   - สิ่งที่ขาด: "วันนี้กับนูรี" (ฟัง 1 → ลอง 1 → ทำกับครอบครัว 1 + ปุ่ม "วันนี้พอแล้ว") ซึ่งตัดสินไว้ 7 ต.ค. และยังไม่ได้เริ่ม (P5-1 ในแผน 7 พ.ย.)
2. **แกนศาสนาที่ผู้ปกครองสลัฟีทั่วโลกมองหาอยู่ในกลุ่ม "เร็วๆ นี้" ทั้งหมด** — อะกีดะฮ์ (เกาะศรัทธา), อัลกุรอาน (ฝึกอ่าน/ท่องจำ), อิบาดะฮ์ (วุฎูอ์ ละหมาด), ดุอาอ์ประจำวัน (มีแค่ 2–3 บทในเกาะมารยาท)
   เว็บจึง "ดูเป็นเว็บเกม-นิทาน-ภาษา" ก่อน "เว็บอิสลาม" ในสายตาคนนอก — การเปิดเกาะศรัทธา (งานที่กำลังทำ) คือการเปลี่ยนภาพลักษณ์ที่สำคัญที่สุดในแผนนี้
3. **ดาวเรียนรู้สร้าง "เศรษฐกิจ" ก่อนมี "หลักสูตร"** — ตอนนี้เด็กได้ดาวจากการดูการ์ตูนจนจบ ไม่ใช่จากการตอบได้ ระบบยุติธรรมสำหรับเด็ก 3–6 แต่สำหรับ 7+ ควรมีคำถามท้ายบท 1 ข้อ (แตะเลือกภาพ) ให้ดาวมีความหมาย — ไม่ขัดการตัดสิน 1 พ.ย. (1 ดาว/บท, ไม่มี streak, ไม่มีรางวัลสุ่ม)
4. **สองวัยในหน้าเดียว** (`AGE_GROUPS.map` ทุกเกาะ) ทำให้มือถือยาวมาก และเด็ก 3 ขวบเลื่อนผ่านบท 7+ ที่ไม่ใช่ของตัว การเลือกวัยที่ `/kids` `/juniors` ไม่ถูกจำ (ไม่มี localStorage สำหรับวัย) จึงต้องเลือกใหม่ทุกเกาะ
5. **เครื่องมือผู้ปกครองดีขึ้นมาก** (ตั้งค่า, จำกัดเวลา, หลักฐาน) แต่ยังขาดสิ่งที่ผู้ปกครองต่างประเทศถามก่อนใช้: หน้าภาพรวมหลักสูตร, "ลูกเรียนอะไรไปแล้ว" (มีข้อมูลใน localStorage อยู่แล้ว แค่ยังไม่แสดง), คู่มือกิจกรรมนอกจอ (P5-4), วิธีติดต่อ/รายงานข้อผิดพลาดของตัวบท
6. **สำหรับโลก ไม่ใช่แค่ไทย:** เนื้อหาไทย-อังกฤษผูกกันแน่น ("ไทยนำ อังกฤษรอง" ในหน้าเดียว) เป็นจุดแข็งของตลาดไทย แต่ตลาดอื่นจะต้องการหน้าภาษาเดียว — โครง `/en` รองรับแล้ว (ดี) ปัญหาคือ **เสียง**: หุ่นยนต์พูดทุกบรรทัดจากไฟล์ mp3 ต่อภาษา การเปิดภาษาที่ 3 จึงต้องอัดเสียงทั้งหมดใหม่ (ราว 900 คลิปต่อภาษา — `find public/audio -name '*.mp3'` = 920) ควรออกแบบให้ **บทเรียนทำงานได้โดยไม่มีเสียง** (มีอยู่แล้ว: `ms` ต่อฉาก) และยอมรับ "ภาษาใหม่เปิดแบบไม่มีเสียงก่อน" เป็นนโยบาย

## 2. Content pipeline และการขยาย

**ที่ดี:** ข้อความทุกบรรทัดเป็น `Text {th,en}` (ไม่มี `en: ""` ค้างเลย), เสียงสร้างจากไฟล์ข้อมูลโดยตรง (`scripts/make-*-voice.mjs`), ภาพผ่าน `optimize-images.mjs` + sha256, ภาพถ่ายมี metadata สัญญาอนุญาตในโค้ด, ชุดตรวจเบราว์เซอร์ต่อฟีเจอร์, Codex brief เป็นแม่แบบตายตัว

**ที่ไม่ขยาย:**

## 3. สถาปัตยกรรมและคุณภาพโค้ด

- **ดี:** Next 16 App Router static ทั้งหมด (`dynamicParams=false`), ไม่มี dependency นอก React/Next/Tailwind (ไม่มี zod, ไม่มี analytics, ไม่มี 3rd-party script — ตรวจ `grep` ใน src = 0), proxy ภาษาเขียนชัด, ไม่มี `transition-all`, `motion-safe:` ใช้ทั่ว, error/404 ครบทั้ง `[lang]`, `games`, `learn`, `global-*`
- **เตือน:**
  1. `src/proxy.ts` เป็นจุดเดียวที่ทำให้หน้าไทยทำงาน — ถ้า host ไม่รัน proxy หน้าไทยทั้งเว็บ 404 (comment บอกไว้แล้ว) ควรมี smoke test หลัง deploy (`curl /learn/moral` = 200) ใน CI/Vercel check
  2. `siteUrl()` ตกเป็น `http://localhost:3000` เมื่อไม่มี env — build ที่ :3200 ที่ตรวจจึงมี canonical/OG เป็น localhost ทุกหน้า **ต้องยืนยันบน Vercel prod ว่า `VERCEL_PROJECT_PRODUCTION_URL` ถูกตั้งจริง** (ดู `view-source` ของ prod) — ถ้าผิด Google จะได้ canonical เพี้ยนทั้งเว็บ
  3. ฟีเจอร์สถานะ (ดาว, เวลา, progress ต่อเกาะ, `lu-arabic-learned-v1`) ใช้ localStorage คนละ key คนละรูปแบบ (`createProgress`, `learning-stars/store.ts`, classroom) — ควรรวม registry key เดียว (`src/lib/storageKeys.ts`) ให้ `parents/content.ts` + `ClearProgress.tsx` อ่านรายการเดียวกัน (ตอนนี้ต้องแก้สองที่ตาม memory)
  4. CSS ต่อฟีเจอร์ 15+ ไฟล์ global (`moral.css` 769 บรรทัด ฯลฯ) ไม่มี scope — ชื่อ class ชนกันได้เมื่อเพิ่มเกาะ ให้ตั้ง prefix ต่อเกาะเป็นกฎ (มีอยู่บางส่วน `.isl-` `.shp-` `.pz-`)
  5. ไม่มี `vercel.json`/`headers()` → ไม่มี CSP, `X-Content-Type-Options`, `Referrer-Policy`, `Permissions-Policy` — เว็บเด็กควรมี (ปิดกล้อง/ไมค์/geolocation ด้วย Permissions-Policy เป็นหลักฐานความปลอดภัยที่โชว์ผู้ปกครองได้)

## 4. ประสิทธิภาพ, มือถือ, a11y, i18n

### 4.1 ผลวัดจริง (LAN, Chrome headless, production build)

LCP ใน LAN ทุกหน้า < 600 ms ไม่สื่อความหมาย — **ต้องวัดบนมือถือจริง/4G** (P1-4 ยังไม่ทำ) เป้า ≤ 2.5 s ตามแผนเดิม

### 4.2 มือถือ

- มือถือแนวนอน: หน้าแรกจอแรกเหลือแต่หัว (ภาพ `home-land.png`) — ควรย่อ header เมื่อ `(orientation: landscape) and (max-height: 500px)` ให้เกาะโผล่
- `/en`: ปุ่ม "Home" 42×48 px (ต่ำกว่า 48 ฝั่งผู้ปกครอง และ 64 ฝั่งเด็ก) — หน้าไทยไม่เป็นเพราะข้อความยาวกว่า ควรกำหนด `min-h-16` ที่ `.ui-pill`
- ยังไม่มีการทดสอบบนเครื่องจริงเลย (LDPlayer ไม่ reproduce bug orbit) — ต้องมี "ตารางเครื่องจริง" อย่างน้อย iPhone Safari 1 เครื่อง + Android Chrome 1 เครื่อง + iPad (มี `scripts/check-ipad-webkit.mjs` แล้วแต่เป็น WebKit บน Windows)
- iOS Safari: เสียงต้องรอ gesture (`unlockRunAudio` ทำแล้ว) แต่ยังไม่เคยยืนยันบน iPhone จริงว่าการ์ตูนเดินต่อเมื่อเสียงถูกบล็อก

### 4.3 a11y

- ผ่าน: alt ครบ, ชื่อปุ่มครบ, landmark ครบ (main/nav/header/footer), focus state มี, `prefers-reduced-motion` ใน base, `lang="en"`/`lang="ar"` บนข้อความรอง
- ค้าง: เขาวงกตแสงกับ screen reader (ค้างตั้งแต่ 7 ต.ค.), เกมลาก-วาง (puzzle, sequence, bead) ไม่มีทางเลือกคีย์บอร์ด/สวิตช์, ไม่มี skip link ไป `main` (ทุกหน้ามี header + nav ก่อน), contrast ของข้อความบนภาพเกาะ (caption ขาวบนฟ้า) ยังไม่วัดด้วยเครื่องมือ

### 4.4 i18n

- โครงพร้อม: `[lang]`, `Text`, dict 2 ไฟล์ (th 546 / en 542 บรรทัด), `LocaleLink`, เสียงต่อภาษา
- ยังไม่พร้อม: ไม่มี hreflang/`alternates.languages` (ตั้งใจ — รอ P4), ไม่มี RTL (ถ้าจะเปิดอาหรับ/อูรดู ต้องตรวจ `dir` ทั้ง layout และ CSS logical properties ตั้งแต่ตอนนี้ เพราะ CSS ใช้ `left/right` เยอะในเกม), วันที่/ตัวเลขไม่ผ่าน `Intl`, ชื่อหุ่นยนต์/เพื่อนยังไม่ผ่าน dict บางจุด
- ข้อเสนอ: ก่อนภาษาที่ 3 ให้ Codex ทำ "RTL smoke" (`dir=rtl` บน `/en`) แล้วถ่ายภาพทุกหน้า — จะเห็นทันทีว่าเกมไหนพัง

## 6. ความปลอดภัยและความเป็นส่วนตัวของเด็ก (COPPA / GDPR-K / PDPA)

**จุดแข็งที่หายาก:** ไม่มีบัญชี ไม่มีคุกกี้ ไม่มี analytics ไม่มี 3rd-party request ข้อมูลอยู่ใน localStorage ล้วน และหน้าผู้ปกครองบอกชื่อ key ทุกตัว — นี่คือ "COPPA by design" ที่โฆษณาได้

**ช่องว่าง:**

| เรื่อง | สถานะ | ควรทำ |
|---|---|---|
| หน้านโยบายความเป็นส่วนตัวเป็นเอกสาร | ฝังในหน้าผู้ปกครองเป็นย่อหน้า | แยก `/parents/privacy` เป็นหน้าของตัวเอง มีวันที่ปรับปรุง, ผู้รับผิดชอบ, ช่องทางติดต่อ, ข้อความเรื่อง server log ของ Vercel, สิทธิ์ลบข้อมูล (= ปุ่มล้างในเครื่อง) — ภาษาอังกฤษต้องตรวจคำ COPPA/GDPR-K ให้ถูก |
| คุกกี้ภาษา `lu-lang` (แผน P4) | จะขัดคำว่า "ไม่มีคุกกี้" | ใช้ `localStorage` แทนคุกกี้ (proxy อ่านไม่ได้ แต่ auto-redirect ครั้งแรกใช้ `Accept-Language` ได้โดยไม่ต้องจำ) → รักษาคำสัญญา "ไม่มีคุกกี้" ไว้ |
| Web Speech API (`speechSynthesis` ใน `speech.ts`) | ใช้เป็น fallback ของ UI บางจุด | เสียงสังเคราะห์ของเบราว์เซอร์บางตัว (Chrome บน Android) ส่งข้อความไป Google — ควรระบุในหน้าผู้ปกครอง หรือปิด fallback เมื่อไม่มี mp3 |
| security headers | ไม่มี | ข้อ 3.5 |
| ลิงก์ออกนอกเว็บในพื้นที่เด็ก | เครดิตภาพถ่าย (Commons) และหลักฐาน Shamela เป็นลิงก์ภายนอก | ลิงก์ Commons ใต้ภาพถ่ายอยู่ในฉากสอนของเด็ก — ย้ายไปท้ายหน้า/หน้าผู้ปกครอง หรือทำเป็นข้อความไม่ใช่ลิงก์ (ข้อ 1.5 ห้ามลิงก์ออกในพื้นที่เด็กเฉพาะเชิงซื้อขาย แต่หลักการ "เด็กกดออกไปไม่ได้" ควรใช้ทั้งเว็บ) |

| อายุผู้ใช้ | ไม่ถาม (ดี — ไม่เก็บ) | ระบุในนโยบายว่า "เราไม่ถามอายุ ไม่เก็บชื่อ" |

ผู้ทำ: **Claude** = วางแผน/ตรวจศาสนา/แก้จุดเล็ก · **sol** = `gpt-6.1-sol` งานกลไก/รีวิว · **astra** = `gpt-6-astra` ภาพ/UX ที่ต้องใช้วิจารณญาณ (effort medium เสมอ — memory `codex-astra-cost`)

### 10.2 สองเดือนข้างหน้า (ถึงกลาง ม.ค. 2027) — "จากคลังบทเรียนเป็นหลักสูตร + เปิดโลก"

| ลำดับ | งาน | ขนาด | ใคร |

### 10.3 ถัดไป (ไตรมาส 1–2 ปี 2027)

- **ภาษาที่ 3** (D4 — เสนอ **อินโดนีเซีย/มลายู** ก่อนเบงกาลี เพราะอักษรละติน ไม่มี RTL และตลาดสลัฟีใหญ่) เปิดแบบ "ไม่มีเสียง" ก่อน แล้วค่อยอัด
- **อัลกุรอานชุดเริ่มต้น** (เสียงอ่านจริงจากกอรีที่ได้รับอนุญาต ไม่ใช่ TTS — ข้อ 1.6) และ **ตัจวีด** ต้องมีผู้รู้ที่เป็นคน (D5) ก่อน — ห้ามเปิดด้วย TTS
- ย้ายเนื้อหาเป็น JSON ต่อภาษา + เครื่องมือแก้สำหรับผู้แปล/ผู้รู้ (ไม่ใช่ CMS ออนไลน์ — เก็บความเป็น static ไว้)
- **ผู้ตรวจศาสนาภายนอก** ลงชื่อในทะเบียนหลักฐาน แสดงบน `/parents/evidence` — นี่คือสิ่งที่ทำให้ "hub ระดับโลก" ต่างจาก "เว็บสวย"
- Freemium (D6) — ถ้าทำ ต้องทำตามแผน 16 ต.ค. ทั้งก้อน (บัญชีผู้ปกครองเท่านั้น, แก้คำสัญญาทุกที่)
- PWA/offline (manifest มีแล้ว): cache บทเรียนที่เปิดแล้วให้เล่นซ้ำได้โดยไม่มีเน็ต — เหมาะกับครอบครัวในประเทศเน็ตแพง
