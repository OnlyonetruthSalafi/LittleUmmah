คำสั่งเจ้าของ: ให้ทุกเกาะที่มีการ์ตูนรองรับการเล่นวิดีโอแนวนอนเต็มจอ
ใช้ FilmLesson ร่วมกันทั้งเกาะมารยาท (/learn/moral), ศรัทธา (/learn/faith-basics)
และสำรวจโลก (/learn/explore) จึงรองรับทุกเรื่องที่ใช้ Film โดยไม่แก้ข้อมูลบทเรียน

พฤติกรรม
- ปุ่มเต็มจอ 64px อยู่ข้างปุ่มปิด มีชื่อไทย/อังกฤษสำหรับ screen reader และ tooltip
- ขอ Fullscreen API บน div ภายใน dialog (API ไม่อนุญาตให้ขอบน dialog โดยตรง)
- จอสัมผัสลองล็อก landscape หลังเข้าเต็มจอสำเร็จ ถ้าล็อกไม่ได้ให้หมุนเครื่องเอง
- ภาพรักษาสัดส่วน ไม่มีการยืดหรือครอบเพิ่ม เรื่องเก่าที่มี captionCrop คงสัดส่วนเดิม
- ระหว่างเล่นซ่อนปุ่มหลัง 3 วินาที แตะภาพ ขยับเมาส์ หรือใช้คีย์บอร์ดเพื่อแสดงปุ่ม
- คำบรรยาย ป้ายคำ จุดหยุดให้เด็กตอบ ภาพสัตว์ เครดิต และปุ่มดูต่ออยู่ใน fullscreen surface
- จอแนวนอนเตี้ย: ช่วงภาพสัตว์ให้ข้อความกับปุ่มอยู่ขวา ไม่บังตัวสัตว์ทางซ้าย
- ออกจากเต็มจอคืน orientation lock ที่เครื่องเล่นเป็นผู้ขอ ปิดบทเรียนคืน focus ให้การ์ด
- หาก API ไม่รองรับหรือปฏิเสธ: ใช้พื้นที่ viewport เต็มและแนะนำหมุนเครื่องแนวนอน
- iPhone ที่มีเฉพาะ webkitEnterFullscreen ใช้ native video พร้อม native captions
  ถึงจุดให้เด็กตอบ/ภาพสัตว์หรือจบเรื่อง จะออกมาที่ HTML เพื่อให้ใช้ปุ่มและป้ายได้ครบ
  ใช้ timeupdate เพิ่มจาก RAF สำหรับ native video; หลังตอบกดปุ่มเต็มจออีกครั้งได้
- กดเต็มจอระหว่างช่วงตอบคำถามหรือการ์ดจบ: ใช้ HTML เต็ม viewport บน iPhone เพื่อไม่ซ่อนป้ายและปุ่ม
- เรื่องเก่าที่ captionCrop ไม่ใช้ native video เพราะ native player จะแสดงข้อความที่ถูกครอบออกกลับมา
- ไม่มีการเรียกเต็มจออัตโนมัติและไม่เปลี่ยนการเคารพ prefers-reduced-motion
