เจ้าของสั่ง 18 พ.ย. 2026: แบบที่ Codex เสนอ (ถาดดาว + ปุ่มตอบ `src/features/math/`) ไม่น่าสนใจ
ให้คิดเนื้อหาตามวัย แล้วสอนผ่านการ์ตูนแบบเกาะอื่น (film-kit) ทำเรื่องแรกก่อน 1 เรื่อง

## หลัก
- การ์ตูนหนึ่งเรื่องสอน **หนึ่งแนวคิด** และต้องนับหรือเห็นได้บนจอ: ของปรากฏหรือวางลงตรงจังหวะที่พูดตัวเลข เว้นระยะห่างให้เด็กนับจากภาพนิ่งได้
- ให้เด็กมีส่วนร่วมโดยใช้จุดหยุดแบบเดิมของ FilmLesson: เด็กนับหรือตอบออกเสียง กดปุ่ม แล้วนูรีเฉลยหลังจุดหยุด
- ตัวเลขที่เป็นตัวเขียนอยู่ในป้าย HTML เท่านั้น ไม่ฝังในวิดีโอ (§3.1) บทพูดเขียนตัวเลขเป็นคำไทย
- นักแสดงเป็นหุ่นยนต์ทั้งหมด (นูรีและผองเพื่อน) ใช้เรื่องในชีวิตประจำวันของเด็ก
- ทุกเรื่องเป็นคณิตก่อน ใส่เรื่องศาสนาได้แต่ไม่บังคับ ถ้าใส่ต้องตรวจตัวบทกับ Shamela ทุกครั้ง

## งานวิจัยหลักสูตรที่ใช้ (18 พ.ย. 2026)
- **Head Start ELOF (สหรัฐฯ, ปฐมวัย 3–5 ปี)** — คณิตศาสตร์อยู่ใต้ด้านการคิด แยกเป็น นับและรู้จำนวน (รวมการเห็นกลุ่มเล็กทันทีโดยไม่นับ และรู้ว่าตัวสุดท้ายที่นับคือจำนวนทั้งหมด), แบบรูป, เรขาคณิตและมิติสัมพันธ์
- **California Preschool/TK Foundations** — นับปากเปล่า จับคู่หนึ่งต่อหนึ่ง และจำนวนของกลุ่ม
- **Common Core K–2** — 5 หมวด: นับและจำนวน (K), การดำเนินการและการคิดเชิงพีชคณิต, ระบบฐานสิบ, การวัดและข้อมูล, เรขาคณิต · ป.1 ขยายการนับและค่าประจำหลัก · ป.2 ฐานสิบและบวกลบ
- **หลักสูตรแกนกลาง 2551 ฉบับปรับปรุง 2560 (ไทย)** — ป.1: เปรียบเทียบและเรียงจำนวนไม่เกิน 100 (ค 1.1 ป.1/2, ป.1/3) วัดความยาวเป็นเซนติเมตร/เมตร (ค 2.1 ป.1/1) · ป.2 มีการชั่ง ตวง เวลา และเงิน
- **หลักสูตรปฐมวัย 2560 (ไทย)** — สอนผ่านประสบการณ์และการเล่น ไม่แยกเป็นวิชา: นับ รู้จำนวน เปรียบเทียบ รูปทรง ตำแหน่ง (ยังไม่ได้ตรวจกับเอกสารต้นฉบับ สพฐ.)

แหล่ง: headstart.gov/school-readiness/article/math-preschool · cde.ca.gov ptklfmathdomain.pdf · ospi.k12.wa.us mathstandards_kindergarten.pdf / grade2.pdf · anubansatit.psu.ac.th (ตัวชี้วัด ป.1)
