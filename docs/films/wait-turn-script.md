# รอคิว — ผลัดกันเล่นทางลูกบอล

ตัวละคร: ครูนูรี, ฮาดี, ซาฟี, รอสซาม

ฮาดีมาต่อท้ายซาฟี รอรอสซามเล่นเสร็จ แล้วผลัดกันปล่อยลูกบอลโดยไม่แซงหรือผลัก

ดัดแปลงจากบท wait-turn ใน src/features/moral/cartoon.ts และ src/lib/lessons.ts ที่ตรวจแล้ว เป็นมารยาททั่วไป ไม่มีอายะฮ์ หะดีษ หรือข้ออ้างศาสนาใหม่ ไม่ใช่การเล่าเหตุการณ์ประวัติศาสตร์

เจ้าของให้ทำต่อเอง 14 พ.ย. 2026 และจะตรวจพร้อมกันเมื่อครบ 3 การ์ด เก็บต้นฉบับเดิมทุกไฟล์

| ช็อต | ภาพและการแสดง | เสียงพูด |
|---|---|---|
| 1 | ใครมาก่อน (intro): ตัวละครเคลื่อนที่และลงมือทำตามเหตุการณ์ | ครูนูรี: วันนี้เพื่อน ๆ มาเล่นทางลูกบอล รอสซามกำลังเล่น ซาฟีรออยู่ก่อนแล้ว<br>รอสซาม: เราปล่อยลูกบอล แล้วดูมันกลิ้งไปข้างล่างนะ |
| 2 | ซาฟีรอก่อนฮาดี (reaction): ตัวละครเคลื่อนที่และลงมือทำตามเหตุการณ์ | ซาฟี: ตอนนี้เรารออยู่ พอเพื่อนเล่นเสร็จ ก็ถึงตาเรา<br>ฮาดี: เราอยากลองด้วย เราจะเข้าไปตรงไหนดีนะ |
| 3 | ดูว่าท้ายแถวอยู่ไหน (think): ตัวละครเคลื่อนที่และลงมือทำตามเหตุการณ์ | ฮาดี: เราเห็นที่ว่างข้างหน้า แต่ซาฟีรออยู่ก่อนแล้ว<br>ครูนูรี: ลองดูนะ ใครมาก่อน ถ้าเพื่อนรออยู่ เราควรไปต่อที่ไหน |
| 4 | ต่อท้ายแถว (queue): ตัวละครเคลื่อนที่และลงมือทำตามเหตุการณ์ | ฮาดี: ซาฟีมาก่อน เราจะไปต่อท้ายแถว<br>ซาฟี: ตรงนี้เป็นท้ายแถว เธอรอถัดจากเราได้เลย<br>ฮาดี: เราจอดตรงนี้ เว้นที่ให้เพื่อน ไม่แซง ไม่ผลัก |
| 5 | รอสซามเล่นเสร็จ (first): ตัวละครเคลื่อนที่และลงมือทำตามเหตุการณ์ | รอสซาม: ลูกบอลลงมาแล้ว เราเล่นเสร็จ ถึงตาซาฟีแล้วนะ |
| 6 | ซาฟีผลัดกันเล่น (second): ตัวละครเคลื่อนที่และลงมือทำตามเหตุการณ์ | ซาฟี: ขอบใจนะ เราจะเข้าไปเมื่อทางว่างแล้ว<br>ฮาดี: เรารออยู่ตรงนี้ ดูลูกบอลกลิ้งไปก่อน |
| 7 | ถึงตาฮาดี (switch): ตัวละครเคลื่อนที่และลงมือทำตามเหตุการณ์ | ซาฟี: ลูกบอลถึงปลายทางแล้ว เราเล่นเสร็จ ถึงตาฮาดีแล้ว<br>ฮาดี: ถึงตาเราแล้ว เราจะค่อย ๆ เข้าไปเล่น |
| 8 | ฮาดีเล่น (third): ตัวละครเคลื่อนที่และลงมือทำตามเหตุการณ์ | ฮาดี: สนุกจัง เรารอได้ แล้วก็ได้ผลัดกันเล่นทุกตัวเลย |
| 9 | ครูทบทวน (recap): ตัวละครเคลื่อนที่และลงมือทำตามเหตุการณ์ | ครูนูรี: มีเพื่อนรออยู่ เราต่อท้ายแถว ไม่แซง ไม่ผลัก แล้วรอให้ถึงตานะ |
| 10 | ชวนเด็กฝึกพูด (practice): ตัวละครเคลื่อนที่และลงมือทำตามเหตุการณ์ | ครูนูรี: ลองพูดตามครูนะ เราจะต่อท้ายแถว แล้วรอให้ถึงตา<br>ครูนูรี: ขอบใจที่ลองพูดนะ คราวหน้าไปเล่น ก็ผลัดกันเล่นแบบนี้ได้เลย |
| 11 | ทุกตัวได้ผลัดกันเล่น (finish): ตัวละครเคลื่อนที่และลงมือทำตามเหตุการณ์ |  |

ทบทวน: ต่อท้ายแถว ไม่แซง ไม่ผลัก รอให้ถึงตา

## การจัดฉากฉบับเผยแพร่ — 14 พ.ย. 2026

ลูกบอลสัมผัสแนวรางด้วยรัศมีจริง หมุนตามระยะกลิ้ง ลงถาดและคงอยู่ในถาดระหว่างรอ ครูนูรีหยิบลูกเดิมไปวางบนจุดเริ่มก่อนเพื่อนคนต่อไป มือผู้เล่นแตะจุดปล่อยจริง ครูออกทางขวาเพื่อไม่เดินผ่านลูกบอลหรือเพื่อนที่ออกทางซ้าย
