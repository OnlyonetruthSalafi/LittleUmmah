# ช่วยเพื่อน — ถามก่อน แล้วช่วยเท่าที่ไหว

ตัวละคร: ครูนูรี, ฟาฮีม, ซาฟี

ซาฟีถามก่อนช่วยฟาฮีมเก็บหนังสือเบา ๆ ส่วนกล่องหนักขอให้ครูนูรีช่วย

ดัดแปลงจากบท help-friend ใน src/features/moral/cartoon.ts และ src/lib/lessons.ts ที่ตรวจแล้ว เป็นมารยาททั่วไป ไม่มีอายะฮ์ หะดีษ หรือข้ออ้างศาสนาใหม่ ไม่ใช่การเล่าเหตุการณ์ประวัติศาสตร์

เจ้าของให้ทำต่อเอง 14 พ.ย. 2026 และจะตรวจพร้อมกันเมื่อครบ 3 การ์ด เก็บต้นฉบับเดิมทุกไฟล์

| ช็อต | ภาพและการแสดง | เสียงพูด |
|---|---|---|
| 1 | กล่องหนังสือ (intro): ตัวละครเคลื่อนที่และลงมือทำตามเหตุการณ์ | ครูนูรี: ฟาฮีมกำลังจัดมุมอ่านหนังสือ ซาฟีแวะมาชวนไปเล่น<br>ฟาฮีม: เราจะย้ายหนังสือไปวางที่ชั้นตรงนั้น |
| 2 | หนังสือหล่น (accident): ตัวละครเคลื่อนที่และลงมือทำตามเหตุการณ์ | ฟาฮีม: อุ๊ย หนังสือหล่นจากกล่องแล้ว<br>ซาฟี: เราเห็นหนังสือหล่นอยู่ เธอจะไปเล่นกับเราไหม |
| 3 | อยากไปเล่นแต่เพื่อนยังเก็บอยู่ (reaction): ตัวละครเคลื่อนที่และลงมือทำตามเหตุการณ์ | ฟาฮีม: เรายังเก็บไม่เสร็จ กล่องนี้ก็หนัก เรายกไม่ไหว<br>ซาฟี: เราอยากไปเล่น แต่เพื่อนยังต้องเก็บของอยู่ |
| 4 | ครูชวนถามก่อน (think): ตัวละครเคลื่อนที่และลงมือทำตามเหตุการณ์ | ครูนูรี: ถ้าอยากช่วย ลองถามเพื่อนก่อนนะว่า ให้เราช่วยไหม |
| 5 | ถามแล้วฟังคำตอบ (apology): ตัวละครเคลื่อนที่และลงมือทำตามเหตุการณ์ | ซาฟี: ฟาฮีม ให้เราช่วยไหม<br>ฟาฮีม: ช่วยเก็บหนังสือเล่มเล็กตรงนี้ให้หน่อยได้ไหม |
| 6 | เก็บหนังสือเบาทีละเล่ม (pickup): ตัวละครเคลื่อนที่และลงมือทำตามเหตุการณ์ | ซาฟี: ได้เลย เราจะหยิบเล่มเล็กทีละเล่ม<br>ฟาฮีม: เราช่วยรับ แล้ววางเรียงไว้ที่ชั้นนะ |
| 7 | ไม่ฝืนยกของหนัก (heavy): ตัวละครเคลื่อนที่และลงมือทำตามเหตุการณ์ | ซาฟี: หนังสือเบา เราช่วยได้ แต่กล่องใหญ่นี้หนักเกินไป<br>ครูนูรี: ของหนักไม่ต้องฝืนยกนะ ขอให้ผู้ใหญ่ช่วยได้<br>ฟาฮีม: ครูนูรี ช่วยย้ายกล่องหนักให้พวกเราหน่อยได้ไหม |
| 8 | ครูช่วยกล่องหนัก (adult): ตัวละครเคลื่อนที่และลงมือทำตามเหตุการณ์ | ครูนูรี: ได้เลย ครูช่วยเอง พวกเธอเว้นทางเดินให้ครูก่อนนะ<br>ซาฟี: พวกเราถอยมารอตรงนี้ ทางเดินว่างแล้ว |
| 9 | หนังสือเข้าที่ (repair): ตัวละครเคลื่อนที่และลงมือทำตามเหตุการณ์ | ฟาฮีม: หนังสือเข้าที่แล้ว ขอบใจที่ถามแล้วช่วยเรานะ<br>ซาฟี: ช่วยกันเสร็จแล้ว คราวนี้เราไปเล่นด้วยกันได้เลย |
| 10 | ทบทวนการช่วยเพื่อน (recap): ตัวละครเคลื่อนที่และลงมือทำตามเหตุการณ์ | ครูนูรี: เห็นเพื่อนต้องการความช่วยเหลือ ถามก่อนช่วย ช่วยเท่าที่ไหว ของหนักให้ผู้ใหญ่ช่วยนะ |
| 11 | ชวนเด็กฝึกถาม (practice): ตัวละครเคลื่อนที่และลงมือทำตามเหตุการณ์ | ครูนูรี: ลองถามเพื่อนตามครูนะ ให้เราช่วยไหม<br>ครูนูรี: ขอบใจที่ลองพูดนะ ถามก่อน แล้วช่วยในสิ่งที่เราทำไหว |
| 12 | ไปเล่นด้วยกัน (finish): ตัวละครเคลื่อนที่และลงมือทำตามเหตุการณ์ |  |

ทบทวน: ถามก่อนช่วย ช่วยเท่าที่ไหว ของหนักให้ผู้ใหญ่ช่วย

## การจัดฉากฉบับเผยแพร่ — 14 พ.ย. 2026

หนังสือตกจากกองที่มองเห็นในกล่อง ซาฟีหยิบทีละเล่ม แขนเคลื่อนต่อเนื่องตามจุดสัมผัส ไม่สลับท่าศอกฉับพลันและไม่ผ่านหน้า หนังสือบนพื้นอยู่หลังตัวละครเมื่ออยู่ไกลกว่า ชั้นหนังสือมีผิวรองรับตรงตำแหน่งวางจริง ส่งเล่มสีเขียวให้ฟาฮีมที่ตำแหน่งเดียวกัน ครูนูรียกกล่อง เคลื่อนย้าย แล้ววางลง กล่องคงอยู่ตำแหน่งใหม่ในฉากถัดไป

## ฉากหยิบ ถือ บิดตัว วาง — เจ้าของอนุมัติ 14 พ.ย. 2026

ซาฟีหยิบเล่มสีฟ้าและเหลืองขึ้นถือ ค้างให้เห็นก่อน บิดตัวไปทางตู้ แล้วค่อยวางและปล่อยมือ ฟาฮีมรับเล่มสีเขียว ถือไว้ แล้วหันตัวไปวางบนชั้น หนังสือที่ถือเคลื่อนตามโครงร่างตัวละคร ไม่เลื่อนผ่านหน้า ใช้เสียงเดิมทั้งหมด
