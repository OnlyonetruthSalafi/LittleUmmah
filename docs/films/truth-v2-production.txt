จุดที่ปรับ
- ลดการบีบตัวระหว่างสลับชุดมุมจากความกว้าง 80% เป็นอย่างน้อย 96%
  ยังคงเป็น 2.5D หลายมุม ไม่ใช่การหมุนโมเดล 3D ต่อเนื่อง
- ใช้เป้าหมายมือเดียวต่อเนื่องสำหรับซาฟีตอนรับ ถือ และติดใบกังหัน
- ใช้ pivot ใบใหม่ตาม metadata ของพร็อพ ทำให้ประกอบเข้ากับ rotor ตรงตำแหน่ง
- ขยับฮาดีเข้าระยะจับตอนตั้งเสากลับ และให้ปล่อยก่อนเอน/ถอยออก
- จัดตำแหน่งฮาดีและทิศหัวในฉากซ่อม แยกส่วนกล้องบนหัวออกจากจุดทำงานมากขึ้น
- ขยายกรอบกล้องช่วงซ่อมและให้ซาฟีถอยไปพื้นที่ว่างด้านซ้าย ศีรษะอยู่ในภาพครบ
- เพิ่มเงาสัมผัสใต้ขาโต๊ะและเศษใบที่ตกพื้น
- เพิ่มคีย์ค้างการหมุนหลังตั้งกังหันกลับ เดิม keyframe ช่วงเริ่มหมุนหลังซ่อม
  ถูก interpolate ย้อนมาทั้งช่วง ทำให้ใบที่เสียค่อย ๆ หมุนระหว่างรอซ่อม
  ฉบับนี้หยุดจนติดใบใหม่และถอนมือ แล้วจึงเริ่มหมุน

หลักฐานตรวจ
- output/car-truth-v2/qa/motion-report.json: ตรวจกริดเวลา 24fps ทั้ง 5,670 จุด
  จุดจับที่ IK ทำงานเต็มน้ำหนัก 227 ตัวอย่าง คลาดเคลื่อนสูงสุดประมาณ 1.958px ที่ 720p
  การเปลี่ยนผู้ถือใบไม่กระโดด; แนวใบตอนติดคลาดประมาณ 0.155px ที่ 720p
  ไม่พบการตัดศีรษะ/โดมซาฟีในช่วงซ่อมที่ตรวจ และกังหันไม่หมุนก่อนซ่อม
  ตัวเลขนี้ตรวจจุดอ้างอิง ไม่ใช่การรับรองการชนหรือการบังของทุกพิกเซลตลอดเรื่อง
- ตรวจภาพจากไฟล์ render.mp4 จริงทั้งภาพรวมและช็อตซ่อม ไม่ใช้ภาพ preview อย่างเดียว
- typecheck และ lint ผ่าน; การทดสอบโครงการ 185 ข้อผ่าน
- production build ผ่านด้วย npm run build -- --webpack ตามเส้นทาง build ที่ CI ใช้
- รายงานไฟล์เว็บ/การเก็บเสียงเดิม: output/car-truth-v2/qa/media-report.json
- รายงานอัปโหลด R2: output/car-truth-v2/qa/r2-upload.json
