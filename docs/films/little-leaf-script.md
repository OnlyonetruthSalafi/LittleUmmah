# ใบใหม่ในกระถาง · A New Leaf in the Pot
การ์ตูนต้นไม้ วัย 3–6 ปี สวนหนึ่งแห่ง ต้นกล้าหนึ่งต้น ครูนูรีพูดคนเดียว
- ครูชี้ให้ดูต้นกล้าในกระถางดินเผา ใบสองใบกางอยู่ มียอดเล็ก ๆ ตรงกลาง “มองต้นไม้เล็กๆ นี้สิจ๊ะ”
- แสงอุ่นพาดผ่านกระถาง “แสงแดดให้ความอบอุ่นด้วยนะจ๊ะ” ครูเว้นจังหวะ “ต้นไม้จริงต้องใช้เวลาจ้ะ”
- แสงเช้าและเย็นผ่านไป ยอดสูงขึ้น ใบใหม่ที่ม้วนอยู่ค่อย ๆ คลี่ออก เด็กมีเวลามองก่อนครูพูดอีกครั้ง
- ครูหันมาหาเด็ก “เด็ก ๆ อยากขอบคุณอัลลอฮ์สำหรับอะไรที่เราเจอวันนี้จ๊ะ?” เว้น 4.2 วินาที
- “อัลลอฮ์ประทานสิ่งดีๆ ให้เรามากมาย เราขอบคุณพระองค์นะจ๊ะ” จบที่ต้นไม้สามใบ

เสียงต้นฉบับเป็นครูนูรีของโครงการจาก car-sun-v5 และ one-seed-world เลือกช่วงเว้นระหว่างประโยคตาม story.mjs และ make-voice.mjs เสียงบรรยากาศสวนเดิมแยกจากบทพูด ภาพไม่มีตัวหนังสือ มีคำบรรยายไทยและอังกฤษแยกไฟล์
