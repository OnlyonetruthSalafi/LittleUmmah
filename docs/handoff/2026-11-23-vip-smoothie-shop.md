# ส่งต่องานให้ Claude · โซน VIP และร้านน้ำปั่น · 23 พ.ย. 2026

## เริ่มตรวจจากการขายแก้วแรก

เปิด dev server จากรากโปรเจกต์ด้วย `npm.cmd run dev -- -p 3123` ถ้ามีเซิร์ฟเวอร์บนพอร์ตนี้อยู่แล้วให้ใช้ตัวเดิม เปิด [เกาะเกม](http://localhost:3123/games) แล้วเข้าโซน VIP หรือใช้ [หน้าร้านบนแผนที่](http://localhost:3123/games/vip#shop) เพื่อเริ่มตรวจเสียงได้ทันที ใช้หน้าต่างส่วนตัวใหม่เพื่อเริ่มจากซาบิรโดยเก็บเซฟเดิมของเจ้าของไว้

1. ให้ครูนูรีเดินไปยังร้าน พื้นที่รอบเกาะยังมีหมอก เมื่อเข้าร้านเด็กเป็นคนขาย มองเห็นมือและปลายแขนของตัวเองจากหลังเคาน์เตอร์
2. ซาบิรเดินมาพูด “อัสสลามมู่อ้าลัยกุ้ม” เด็กเลือกคำตอบรับสลาม แล้วกดรับออเดอร์ในป๊อปอัปถัดไป
3. แตะส้มและกล้วยในตะกร้า กดสวิตช์บนเครื่องปั่น แตะแก้วเพื่อเท แล้วแตะลูกค้าเพื่อเสิร์ฟ แก้วแรกเปิดลูกศรนำทาง เด็กเปิดหรือปิดลูกศรได้
4. แตะเหรียญบนถาดครั้งเดียว ยอดเงินเพิ่ม 5 เหรียญและได้ยินเสียงเหรียญ ซาฟีเป็นลูกค้าคนที่สอง เมื่อถึงเคาน์เตอร์ต้องได้ยินคำสลามจนจบแม้เด็กแตะตอบทันที ลองปิดเสียงเพื่อทวนทั้งสองจังหวะ
5. เมื่อลูกค้ามา ให้เลือกคุยภายหลังแล้วแตะลิ้นชักเพื่อซื้อของ ตะกร้าสตรอว์เบอร์รีใช้ 5 เหรียญและเพิ่มสูตรใหม่ เครื่องปั่นทองใช้ 12 เหรียญและลดเวลาปั่น

## ทดสอบก่อนส่งรอบถัดไป

จากรากโปรเจกต์ รัน `npm.cmd run lint`, `npm.cmd test` และ `npm.cmd run build` โดยชุดทดสอบเฉพาะเกาะอยู่ใน `tests/vip-island.test.mjs`

เปิด dev server แล้วรัน `node scripts/check-smoothie-sound.mjs http://localhost:3123` สคริปต์เล่นตั้งแต่ซาบิรเข้าร้านจนซาฟีทัก ตรวจสัญญาณเสียงที่ส่งออก จำนวนครั้ง ระยะเวลาที่เล่น และทดสอบซ้ำเมื่อปิดเสียง บนเครื่องใหม่ตั้ง `PLAYWRIGHT_CORE` ให้ชี้ไปยังแพ็กเกจ playwright-core และ `CHROME_PATH` ให้ชี้ไปยัง Chrome หากตำแหน่งต่างจากเครื่องโปรเจกต์

ก่อนเผยแพร่ ควรฟังเสียงรับเงินและเสียงลูกค้าจากอุปกรณ์จริงอีกครั้ง โดยเฉพาะคำสลามของฮาดีซึ่งยังรอตรวจการออกเสียงด้วยหู ส่วนผลตรวจอัตโนมัติบอกได้ว่าเสียงเล่นถึงปลายทางและเล่นครบ

รอบส่งมอบ 23 พ.ย. ผ่าน lint, production build พร้อม TypeScript, ชุดทดสอบ 202 รายการ และสคริปต์เบราว์เซอร์ตรวจเสียงทั้งตอนเปิดและปิดเสียง

ใน working tree เครื่องเดิมมีงานภาพยนตร์ หนังสือป๊อปอัป และชุด sprite อื่นที่ทำค้างแยกกัน ดู `git status` ก่อนจัดชุดงานถัดไป
