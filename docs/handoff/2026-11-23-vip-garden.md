- ลำดับ: เพื่อนเดินมาที่ประตูรั้ว ให้สลาม → เด็กตอบสลาม → เพื่อนขอผัก (เสียงพากย์) → รับคำขอ (ใช้ 1 รอบดาวเรียนรู้) →
  ลากจอบถูไปมาบนแปลงจนพรวนเสร็จ → ลากเมล็ดลงแปลง → ถือบัวรดน้ำค้างไว้เหนือแปลง → ต้นโต 3 ขั้น (โตเฉพาะตอนมีน้ำ น้ำหมดแล้วเหี่ยว มีหยดน้ำเตือน แต่ไม่ตาย) →
  วัชพืชงอกกลางทาง โตช้าลงครึ่งหนึ่งจนกว่าจะดึงออก → ดึงผักขึ้น (ลากขึ้น) ลงตะกร้า → ลากตะกร้าไปให้เพื่อน → เพื่อนดีใจ ขอบคุณ จ่ายเหรียญร้าน
- แตะเลือกเครื่องมือแล้วแตะแปลงก็ทำได้ (คีย์บอร์ด Enter ได้ทุกขั้น)

  ภาพ Codex `gpt-6-astra` ตาม `docs/briefs/VIP-7-garden-bench-art.md` (imagegen 2/5): `garden/seed-sack.webp`, `garden-bg/bench-top.webp` ต้นฉบับ `output/garden-art/bench/`
